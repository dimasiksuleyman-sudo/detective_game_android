# Оригиналы арта «Синей совы»

58 выбранных PNG, сгенерированных через image_gen по STYLE_CORE и §5 арт-библии: обложка, 3 локации, 10 крупных планов, 5 улик, 36 портретов, 3 реконструкции. В этом PR добавлены 52; прежние 6 сохранены. Полный список, размеры и статусы — [../ASSETS.md](../ASSETS.md).

`prompts.json` содержит точные промпты новых изображений и референсы. Для каждого актёра выбрана neutral из трёх вариантов; пять эмоций получены отдельными правками выбранного мастера. Отбракованные варианты вне git. Авторское одобрение владельца отмечается отдельно от факта генерации (ADR-020).

`manifest.json` задаёт выбранные исходники, реальные размеры PNG, игровые пути и качество WebP. Конвертация из корня: `npx tsx tools/build-pack.ts --art-only`. Исходники в APK не входят. Контакт-листы: `docs/devlog/assets/m3-art/`.

Существующий кабинет сохраняет исправления владельца: полный меловой контур, закрытая сторона стола к входу, уменьшенная статуэтка. Существующий крупный план статуэтки и координаты скола не менялись.
