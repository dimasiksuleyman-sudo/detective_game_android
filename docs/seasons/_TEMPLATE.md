# Сезон N — «Название»

Лист сезона (ADR-031). Общие правила картинок — `docs/05-art-bible.md`. Порядок запуска — `docs/CASE-RUNBOOK.md` → «Новый сезон».

## Мир

Страна, город или место, эпоха, время года, реальность (обычная / ближнее будущее / иная). Тон. 3–5 предложений. Этот же текст получит ИИ-допрос.

## Стиль картинок

- Описание стиля по-русски (2–3 строки).
- **STYLE_CORE сезона** (английский, добавляется в каждый промпт; в конце обязательно «No text, no letters, no numbers, no watermark, no logo, no signature.»):

```
...
```

- Палитра картинок: 5–7 цветов HEX с ролью. Интерфейс не меняется — проверить, что картинки читаются на тёмном фоне `#12181D`.
- Пробные картинки (локация + портрет), одобренные владельцем: пути к файлам.
