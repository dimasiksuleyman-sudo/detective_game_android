# 2026-11-12-36 — Несколько дел

**Этап:** шаг 0 CASE-RUNBOOK · **Ветка:** feature/multiple-cases от main 023e650 · **Версия:** 0.3.5 / code 9.

## Цель

Подготовить приложение ко второму делу отдельным кодовым PR без изменения контента и канона. PR 2 начинается только после слияния PR 1, от свежего main.

## Что сделано

- Реестр встроенных JSON, S03 с обложками и метаданными. Настройка новой партии отделена от сохранённой, диапазон игроков берётся из дела.

- Колёсики сбрасываются при смене замка/дела/длины. Схема уже разрешала 1–8 цифр; пилот остаётся четырёхзначным. Длинный ряд прокручивается.
- Тестовая фикстура с другим id/брифингом и трёхзначным кодом 214 находится вне public, подключается только в e2e. Production-проверка запрещает её маркеры.
- ADR-030, актуальный STATUS, MT-023 и команды Android Studio. Канон пилота и библия второго дела не менялись. Арт/озвучка не генерировались.

## Проблемы и решения

- В облачной среде не было checkout: найден подключённый репозиторий, клонирован в work/, main обновлён до начала ветки.
- Первый e2e запуск совпал с установкой Chromium и не проверял приложение. Затем исправлены поля тестовой фикстуры по действующей схеме и локаторы нового сценария (декоративная картинка, точка в сообщении ошибки, продолжение из меню/экран передачи).
- Старые проверки ожидали envelope v3. Они теперь требуют v4, сохраняя все проверки улик/заметок/доски/повторного осмотра.
- Без caseId у нового v4 или при неизвестном деле чтение прекращается без перезаписи. Тихий fallback на пилот исключён, чтобы не повредить прогресс.

Команды — HOWTO-run.md, раздел «Несколько дел». В production только «Синяя сова»; фикстура доступна лишь браузерным e2e. Нативная компиляция/телефон ещё не проверены, APK агент не собирает.
