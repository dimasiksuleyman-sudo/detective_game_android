# 2026-11-11-10 — Приёмочные сценарии M1 и Android 0.1.0

**Этап:** M1 · **Пункт roadmap:** e2e, сохранение, приватность, debug APK · **Коммит:** исправления и эта запись вместе.

## Цель

Проверить реальные игровые переходы и подготовить повторяемую Android-сборку.

## Что сделано

- Пройдены одиночная партия до победы и партия двух игроков с выбыванием первого, на 360×800 и 412×915.
- Проверены восстановление сохранённой партии, короткое нажатие передачи, защита прямого адреса и web visibility.
- Добавлен отдельный сценарий давления на Веру, предъявления ежедневника, слома и появления канонического факта в блокноте; проверены заметки и вкладки.
- Исправлены размеры зоны локации при незагруженном изображении. E2E использует настоящие клики, без force и отключения проверок.
- Восстановлены реакции на улики из пилота, описания улик содержат понятный текст вместо технических путей, крупные планы отображаются на экране находки.
- Генерируются скриншоты меню, выбора/настройки/брифинга, передачи, локаций, улик, допроса, блокнота/вкладок, доски, обвинения и финала для двух размеров экрана.
- CI расширен обязательными case:validate и test:coverage. Нативный Capacitor App синхронизирован в Android; версия 0.1.0 / code 2.
- Локальный APK собран: BUILD SUCCESSFUL, 123 задачи, 43 с. apksigner подтвердил подпись; aapt — appId, версию, minSdk 26 и target 36.

## Проблемы и решения

- Визуальный просмотр выявил служебный id в тексте сейфа — заменён описанием находки. Также последнее приватное сообщение могло появиться внизу общей доски; вывод ограничен экранами действия, сообщение сбрасывается при начале следующего хода. Добавлены регрессии отсутствия приватной реплики на доске и пустого сообщения у следующего игрока.
- Скриншот после клика мог сохранить предыдущий экран; добавлены ожидания конкретных заголовков, вместо задержек или принудительных кликов.

- Переход браузера reload сохраняет hash и сразу открывает защищённую передачу, поэтому сценарий нового запуска открывает корневой URL, затем «Продолжить».
- getByLabel с exact захватывал содержимое options; выбор делается по доступному имени combobox. Показанный UI не изменялся для обхода теста.
- После расширения скриншотов smoke использовал неопределённый info; заменено на test.info().
- Изображения M1 остаются заглушками, фото и анимации финального вида — M3.

## Отклонения от плана

Уточнения описаны в ADR-006; нового архитектурного выбора на этом шаге нет.

## Как проверить владельцу

На ПК переключиться на codex/m1-classic-game, выполнить npm.cmd ci и npm.cmd run android:sync, открыть android в Android Studio с JDK 21, запустить на телефоне. Выполнить MT-009 и MT-003. APK из CI будет указан в итоговом отчёте после успешного прогона.

## Ручная проверка

M1 на физическом телефоне агент не проверял. MT-009, MT-003 и функциональная часть MT-008 ожидают владельца; результаты M0 не переносятся автоматически.
