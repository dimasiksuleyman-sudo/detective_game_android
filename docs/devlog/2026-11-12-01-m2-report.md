## Проблемы и решения

- Нет ключа для фактической проверки API/качества → все автотесты на моке; первый реальный smoke выполняет владелец на телефоне. До успеха одного вопроса полный бенчмарк запускать не предлагается.
- Владелец собирает локально → один контрольный CI APK обоснован новыми native-плагинами; документационный отчёт не требует нового APK.
- Проверки M0 ранее приняты, M1 не подтверждены → не переносим отметку приёмки на новые игровые механики или ключ.

## Отклонения от плана

ADR-008 — secure storage; ADR-009 — фактические API-id и предварительная модель; ADR-010 — детерминированный фолбэк, предъявление и метрики. Частота APK — ADR-007. Отсутствующий бенчмарк явно разрешён roadmap M2 при отсутствии ключа и вынесен в STATUS. Окончательная приёмка M2 не объявляется до физических результатов.

## Как проверить владельцу

На ПК Windows открыть PowerShell и выполнить сверху вниз:

```powershell
Set-Location 'D:\Projects\detective_game_android'
git fetch origin
git switch codex/m2-ai-interrogation
git pull --ff-only
npm.cmd ci
npm.cmd run android:sync
& "C:\Program Files\Android\Android Studio1\bin\studio64.exe" "D:\Projects\detective_game_android\android"
```

В Android Studio дождаться Gradle Sync, выбрать JDK 21 и TECNO, нажать Run. На телефоне выключить режим полёта. **Настройки → ИИ-допрос → Ключ aitunnel → «Проверить и сохранить ключ»**. Должны появиться подтверждение и баланс; поле очистится. Сам ключ вводить только там, в чат не отправлять. Затем создать новую партию: Синяя сова → настройка игроков → режим ИИ. Начать допрос и задать один свободный вопрос. Он оплачивается с собственного баланса; проверка ключа не генерирует текст. Старое классическое сохранение в ИИ не конвертируется.

Сообщить результат проверки баланса и первого вопроса, модель, задержку и стоимость/текст ошибки без ключа. После успеха выполнить полный MT-004/010; скрипт бенчмарка до 60 запросов — отдельное действие по HOWTO с --allow-paid.

## Ручная проверка

MT-004: перезапуск приложения/телефона, хранение и удаление ключа. MT-010: реальный ответ, расходы, офлайн, отмена, Clipboard/Logcat и доступность моделей. MT-003/009: приватность/сохранение и полная классическая партия M1. Все ожидают результатов владельца; точные шаги в MANUAL-TEST-QUEUE.
