# 2026-11-12-18 — Отложенная проверка M2 и подключение арта M3

**Этап:** M3, первый шаг по команде владельца «Го дальше».

## Цель

Записать отложенные телефонные проверки пакета M2 и подключить четыре подготовленные иллюстрации с корректными зонами осмотра.

## Что сделано

Владелец получил ветки через git fetch, но проверку новой маски ключа и порядка вопросов отложил. Эти проверки не считаются пройденными; добавлен MT-014. Начата ветка codex/m3-pilot-art на основе проверенного кода пакета M2. Подготовка WebP выполняется отдельно от генерации, оригиналы PNG сохраняются.

## Изменённые файлы

STATUS, MANUAL-TEST-QUEUE, HOWTO, INDEX и эта запись — состояние и журнал; ADR-016 — пайплайн готового арта. Реализация и полный список дополняются по завершении шага.

## Команды

Чтение требований, git switch -c codex/m3-pilot-art. Далее: подготовка WebP, валидатор ресурсов, lint/typecheck/unit, production build, e2e и android:sync.

## Тесты

Предыдущий пакет M2: CI PR №4 успешен, 71 unit и 22 e2e локально. Эти результаты не подменяют отложенную проверку на телефоне. Новые проверки M3 выполняются после реализации.

## Проблемы и решения

Готовы только обложка и три локации. Портреты, крупные планы, улики и реконструкции пока заглушки. Полный M3 и дополнительный поиск скола не объявляются выполненными. Координаты зон старых заглушек не совпадают с рисунками и должны быть заменены вместе с изображениями.

## Отклонения от плана

ADR-016 описывает частичное подключение арта без изменения схемы дела и без преждевременного объявления завершения M3.

## Ручная проверка

MT-014 — маска ключа/порядок вопросов, отложено владельцем. MT-011 — изображения, зоны и производительность на телефоне после установки M3. MT-012 — детальный осмотр пока не реализован.

## Следующий шаг

Подключить четыре изображения, проверить осмотр и записать результаты. Затем продолжать оставшиеся пункты M3.

## Результат реализации и проверки

- tools/build-pack.ts: подготовка арта по art/pilot/manifest.json, проверка входов/выходов и допустимых путей, весь набор проверяется до записи. ZIP явно не реализован. Ключи/сеть не используются.
- src/content/illustrations.ts и GameApp: отличают готовую обложку от заглушек, над готовой картинкой нет сообщения «Временное изображение». CSS резервирует её пропорции; зоны комнат прозрачны, клавиатурный фокус и доступные имена работают.
- public/cases/case-001-blue-owl/: четыре WebP заменены, в case.json обновлены rect всех 13 зон. Схема и игровые факты не менялись. Байты: 134050 + 274038 + 283574 + 347392 = 1039054.
- Валидатор ресурсов/решаемости, lint/typecheck, 71 unit, e2e 24/24 на двух размерах успешны. Production dist проверен и синхронизирован с Android; три native-плагина. Движок: 98,89% строк / 90,04% ветвей. Модели во всех тестах — MockAiClient, платных вызовов нет.
- tests/e2e/classic.spec.ts дополнен загрузкой каждой новой локации, проверкой прозрачности зон и осмотром статуэтки; все прежние сценарии сохранены. Скриншоты пишутся в docs/devlog/assets/m3/, исторические M2 не перезаписаны.
- Просмотрены три новых локации при 360×800: плашек нет, рисунки не обрезаны. Физическое попадание пальцем/производительность ждут MT-011. Обложка также просмотрена как исходник; крупные планы и актёры пока заглушки.
- STATUS переписан как актуальный срез без противоречивых накопленных отметок; исторические наблюдения остаются в devlog. README/HOWTO/арт-библия/README исходников обновлены.

## Как проверить владельцу позднее

Когда вернётесь к телефону: обновить codex/m3-pilot-art → npm.cmd ci → npm.cmd run android:sync → Run в Android Studio с JDK 21. Для нового UI — MT-014, для обложки/локаций — MT-011. Сейчас владелец явно отложил проверки, их не запрашиваем и не помечаем пройденными. Детальный поиск скола MT-012 пока недоступен.
