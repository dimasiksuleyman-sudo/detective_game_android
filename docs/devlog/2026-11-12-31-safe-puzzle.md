# 2026-11-12-31 — Сейф как головоломка

**Этап:** M3 / point-and-click · **Пункт roadmap:** осмотр предметов и интерфейс пилота · **Ветка:** feature/safe-puzzle, один PR в main. База обновлена с 1e632a6 до 9858033 во время работы.

## Цель

Реализовать четыре утверждённых владельцем пункта: ручной кодовый замок, дедукцию даты, четыре предмета и самостоятельный поиск подписи. Не собирать APK.

## Что сделано

- Четыре колёсика 0–9, тап/свайп/+/−/клавиатура/aria. Неверные попытки бесплатны, показывают «Не подходит» и тряску. ui-tap не дублируется глобальным обработчиком; первое открытие играет новый локальный safe-open. Открытие — одна зона кабинета; повтор/предметы бесплатны.
- Код не выдаётся числовым фактом. Ежедневник даёт намёк, оборот фото — отдельную дату. Ольга говорит о памятных датах, Шеф с раунда 4 напоминает об открытии бара. Валидатор требует AND двух источников; движок принимает услышанный код без них.
- Четыре области внутри сейфа: бухгалтерия, наличные с отказом Вере, черновик завещания, визитка юриста. У каждого своя улика/факт; нет автоматической выдачи/подсветки. Ложные следы объясняются существующими фактами долга/алиби и гостиницы в финале.
- Разворот бухгалтерии содержит таблицу и естественную подпись. Факт автора и денежный слом Глеба закрыты до самостоятельного осмотра подписи; порог стресса и правила обвинения сохранены.
- Пять PNG сгенерированы по STYLE_CORE пачками: два крупных плана, затем три предмета. Выбраны только итоговые оригиналы, внесены в манифест/ASSETS, преобразованы в WebP. Два контакт-листа показаны владельцу без ожидания одобрения. Заглушек нет, статусы честно «сгенерировано».
- ADR-025, схема дела v3 / пилот v4 / minAppVersion 0.3.3, сохранение v3. Миграция сохраняет открытый сейф, прежнее знание подписи, доску, заметки и признания; новая v3-партия при загрузке подпись не получает. Приложение 0.3.3 / code7.
- В ветку включён актуальный main с пятью музыкальными темами и полным запретом облачной сборки APK (ADR-024). Чужие изменения сохранены.

## Команды и тесты

`git pull --ff-only origin main`, fetch/rebase после нового main; `npx tsx tools/build-pack.ts --art-only`; format, lint, test:coverage, case:validate, android:sync (включает typecheck, web-build, verify:production и cap sync), e2e. APK/Gradle не запускались, ключи/реальный ИИ не использовались.

**Итог:** lint, typecheck, валидатор, production build/verify и cap sync прошли; **99/99 unit**, покрытие строк движка **97,30%**, полный прогон **84/84 e2e** на 360×800 и 412×915. Сценарии: неверный/верный код, ввод без фактов, четыре предмета, клавиатура/свайп, подпись и денежный слом, удаление каждого источника дедукции, миграция, два минимальных пути до победы. Тесты прежних функций не удалены; старые помощники открытия сейфа теперь вращают колёсики.

Кратчайший путь с известным кодом — одна зона и победа в первом раунде с найденной подписью. Дедукция — фото, затем ежедневник+сейф: три зоны за два хода. Это проверка действующих правил обвинения с одним ключевым доказательством, не утверждение, что игрок без знания развязки обязан догадаться так быстро.

## Проблемы и решения

- Число открытий/условия канона и возможность сообщить код вслух решают разные задачи: валидатор проверяет знания, движок — введённые цифры (ADR-025).
- В тесте допроса давление после двух болезненных вопросов приводило к адвокату раньше предъявления. Тон переключён на нейтральный перед предъявлениями; порог/ограничения игры не ослаблялись.
- Первый тест переноса искал «Продолжить» после перезагрузки личного маршрута, хотя защита уже показывала передачу. Исправлен вход через главное меню, селектор открытого сейфа учитывает отметку ✓; проверка миграции сохранена.
- Main получил музыку и занял номер ADR-024/devlog-30. Ветка обновлена, новый ADR перенумерован 025, журнал — 31; конфликт манифеста разрешён сохранением пяти тем и добавлением только safe-open. Нативный CI из main не возвращался.
- Старая бухгалтерия уже сообщала автора: перенос сохраняет это знание, а новые сохранения не раскрывают подпись при загрузке.

## Отклонения от плана

ADR-025 фиксирует согласованные изменения канона/схемы и стоимость открытия. К четырём запрошенным картинкам добавлен разворот бухгалтерии для осмотра подписи. Новая подсказка Шефа текстовая; существующие восемь голосовых файлов совпадают с прежними репликами, платная перегенерация не запускалась.

## Как проверить владельцу

Единый **MT-019** в MANUAL-TEST-QUEUE: обновление старой партии без удаления данных, колёсики пальцем/TalkBack, щелчки и звук открытия, бесплатная ошибка, код без подсказок, четыре предмета, дедукция, подпись/масштаб/слом, сохранение/передача/системная «Назад» и офлайн. Новая версия подготовлена для локального Run в Android Studio по HOWTO; итог слышимости и удобства Android ожидает владельца.
