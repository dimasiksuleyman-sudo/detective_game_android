# 2026-11-12-16 — ИИ недоступен после удаления ключа

**Этап:** M2, ручная проверка владельца.

## Цель

Подтвердить блокировку новой ИИ-партии без сохранённого ключа.

## Что сделано

Владелец открыл выбор режима новой партии после удаления ключа и подтвердил: «Да, ИИ теперь недоступен». Вместе с предыдущим шагом подтверждены удаление/перезапуск и блокировка выбора ИИ. Код не менялся, исправления остаются в общей очереди.

## Изменённые файлы

STATUS, MANUAL-TEST-QUEUE, INDEX и эта запись — результат проверки.

## Команды

Форматирование; npm run lint, npm run typecheck, npm test перед коммитом.

## Тесты

Подтверждено владельцем на TECNO CAMON 30S / Android 16: выбор ИИ без ключа недоступен. Работа классики после удаления проверяется следующим шагом. Полные MT-004/010 ещё не закрыты: инструментальная проверка Logcat, перезагрузка телефона и прочие непроверенные пункты остаются открытыми. APK не собирается.

## Проблемы и решения

Новых ошибок в этом шаге не сообщено. Результат не заменяет проверку классики без ключа.

## Отклонения от плана

Нет.

## Ручная проверка

Следующий шаг: в режиме «Классика» без ключа и без сети начать партию и получить ответ на готовый вопрос. Если при старте требуется заменить текущую партию, учитывать предупреждение игры о перезаписи сохранения.

## Следующий шаг

Продолжить по одному действию с подтверждением владельца, затем согласованный пакет исправлений.
