# 2026-11-13-03 — Чёткая иконка и страховка заставки

**Этап:** M4 / QA. **Ветка:** claude/lucid-wozniak-3iu7wi от main после слияния PR 24.

## Цель

Проверить PR 24 (иконка, сплэш, прокрутка обыска) и исправить найденное до первой сборки 0.3.4 у владельца.

## Что сделано

- **Проверка PR 24:** CI зелёный; локально lint, typecheck, 106/106 unit, LFS, валидатор, сборка и e2e 90/90. Иконка и заставка просмотрены глазами. PR влит в main.
- **Найдено и исправлено — мыльная иконка.** Слои адаптивной иконки (foreground, background, monochrome) должны быть 108dp, а генератор положил их размером 48dp (на xxxhdpi 192 px вместо 432 px). Android растягивал их в 2,25 раза. Теперь `tools/finalize-app-assets.ts` нарезает все три слоя из исходников 1024² в точном размере каждой плотности: 81 / 108 / 162 / 216 / 324 / 432 px. Пропорции мотива не изменились (сверено по границам непрозрачной области).
- **Тест:** `appAssets.test.ts` проверяет точные пиксели каждой из шести плотностей: обычная/круглая иконка 48dp, слои 108dp. Старый тест проверял только «квадрат» и ошибку не ловил.
- **Страховка заставки:** раньше заставка скрывалась только по готовности сохранения; если бы хранилище не ответило, лупа висела бы вечно. Добавлен таймер 8 с (`armLaunchSplashFallback` в `main.tsx`), в вебе не ставится. Два новых unit-теста.
- **Документы:** проверка иконки получила номер **MT-022** (MT-021 уже занят проверкой «Спросить»/«Ржавый якорь»). Строка журнала 2026-11-12-35 перенесена на место по дате. STATUS переписан, CHANGELOG дополнен.

## Тесты

Все unit зелёные (включая 2 новых для заставки и точные размеры иконок), e2e 90/90. Реальный ИИ не вызывался. Gradle не запускался (ADR-024).

## Проблемы и решения

Генератор `@capacitor/assets` в режиме custom создаёт слои размером обычной иконки и добавляет inset в XML. Агент убрал inset, но размер слоёв остался 48dp. Ручная правка PNG запрещена, поэтому нарезка вынесена в скрипт.

## Отклонения от плана

Нет. ADR-029 остаётся в силе.

## Ручная проверка

MT-022 (иконка, заставка, нижние кнопки): иконка на рабочем столе должна быть чёткой, без размытых краёв лупы.
