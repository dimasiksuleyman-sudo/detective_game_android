## Проблемы и решения

Первые варианты крупного плана показывали фурнитуру слишком низко. По двум уточнениям владельца подняты ручка, задвижка и повреждение косяка; второе — ещё примерно на 30%. Исправлен и относительный масштаб ручки, чтобы полноразмерная дверь не казалась низкой. Промежуточные варианты в git не включаются. Для общего плана использована только небольшая правка исходного кадра, положение шести остальных зон проверено отдельно. Историческое имя h-door-chain сохраняется по библии.
