# 2026-11-12-11 — Сетевая ошибка, тосты и идея озвучки

**Этап:** проверка M2, предложения полировки M4.

## Цель

Зафиксировать результат офлайн-запроса и предложения владельца без немедленной правки кода.

## Что сделано

По скриншоту владельца при выключенной сети показано «Нет связи с ИИ», приложение сообщает, что реплика не списана и доступны офлайн-вопросы. Видно дублирование фразы о несписании. Это подтверждает показ ошибки, но фактический счётчик и выполнение офлайн-вопроса ещё требуют проверки. Владелец предлагает тосты, разрешая пока оставить постоянный блок. Идея озвучки начальной истории через Cartesia.ai записана как кандидат, без API-вызовов и выбора провайдера.

## Изменённые файлы

ADR-015 — решения и ограничения; roadmap — тосты и кандидат озвучки; STATUS — результаты/очередь/вопросы; HOWTO — текущая доступность; MANUAL-TEST-QUEUE — результаты и будущая проверка; INDEX и эта запись — журнал.

## Команды

Форматирование документов; npm run lint, npm run typecheck, npm test перед коммитом.

## Тесты

На физическом телефоне владельца подтверждён показ сетевой ошибки. Квота известна только по тексту сообщения, независимое наблюдение счётчика не сообщено. Воспроизведение, тосты и Cartesia не реализованы и не проверены; APK не собирается.

## Проблемы и решения

Постоянное сообщение велико и повторяет одну мысль. Тост запланирован на полировку; во время разработки блок разрешён владельцем. Учёт расходов не следует прятать в исчезающее сообщение.

## Отклонения от плана

ADR-015 фиксирует новые пожелания; схема и код не меняются.

## Ручная проверка

Следующий шаг: не включая интернет, задать один готовый офлайн-вопрос и убедиться, что ответ появился. Будущие тосты и озвучка — отдельная проверка после реализации.

## Следующий шаг

Продолжать сбор результатов по одному действию; затем пакет согласованных исправлений.
