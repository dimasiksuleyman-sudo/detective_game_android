# 2026-11-12-13 — Возврат после сворачивания при ИИ-запросе

**Этап:** M2, проверка владельцем.

## Цель

Зафиксировать реальный маршрут возврата, не объявляя отмену полностью проверенной.

## Что сделано

Владелец свернул приложение до получения ответа ИИ. После возобновления увидел главное меню, нажал «Продолжить» и получил экран передачи игроку. Прямого открытия личного экрана по этому сообщению не было. Не подтверждены отсутствие позднего ответа и неизменность счётчика реплик; следующий шаг — пройти передачу и проверить историю прерванного вопроса.

## Изменённые файлы

STATUS, MANUAL-TEST-QUEUE и INDEX — результат; эта запись — журнал. Код не менялся.

## Команды

Форматирование; npm run lint, npm run typecheck, npm test перед коммитом.

## Тесты

Ручная проверка на TECNO CAMON 30S / Android 16: маршрут главное меню → Продолжить → передача. Это подтверждает экран передачи на пути к личным данным, но не отсутствие утечки в миниатюре последних приложений, не причину открытия меню и не полную отмену запроса. Возврат в меню не объявляется ни исправленной ошибкой, ни обязательным поведением без дополнительной диагностики.

## Проблемы и решения

Ожидали увидеть передачу сразу; фактически сначала показано меню. Наблюдение сохранено для оценки в пакете правок. Возможное пересоздание приложения системой не установлено.

## Отклонения от плана

Нет изменений правил или реализации.

## Ручная проверка

Пройти передачу удержанием и проверить наличие ответа на прерванный вопрос. Счётчик реплик и поздние изменения нужно подтвердить отдельно, если до сворачивания счётчик не записан.

## Следующий шаг

Продолжить проверку по одному действию с подтверждением владельца.
