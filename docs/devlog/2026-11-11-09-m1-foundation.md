# 2026-11-11-09 — Основа M1: контент, движок и классические экраны

**Этап:** M1 · **Пункт roadmap:** реализация классического ядра · **Коммит:** реализация и эта запись вместе.

## Цель

Заменить каркас рабочим классическим расследованием, сохранив чистую детерминированную модель и офлайн-доступность встроенного дела.

## Что сделано

- M1 начат по команде владельца «го дальше» после приёмки M0; отдельная ветка codex/m1-classic-game наследует принятый M0.
- Перенесены 23 факта, 9 улик, 3 локации, 13 хотспотов, 4 подозреваемых и 26 вопросов. Изображения — WebP-заглушки с подписями UI.
- Zod-схема, семантический валидатор ссылок/решения/достижимости/алиби/ложных следов/безопасности/объёма и CLI проверки размеров ресурсов. Добавлена разрешённая планом разметка Fact.proves через ADR-006.
- Чистый reduce реализует начало/передачу/конец хода, обыск, классический допрос, предъявление, стресс, адвоката, публикацию, заметки, обвинение, финальную фазу, очки и подсказки. Подготовлена безопасная граница результата ИИ, без подключения клиента.
- Zustand соединяет движок с версионированным IndexedDB-сохранением. Действие подтверждается после записи; повреждённая партия не затирается автоматически.
- Реализованы настройка игроков, брифинг, удержание 1 секунду, хаб, локации с координатными зонами, просмотр улик и документов, допрос, четыре вкладки блокнота, доска, мастер обвинения, финал. Документы рендерятся из fields, а не из изображения.
- Жизненный цикл — через src/platform/appLifecycle, Android App plugin и web visibility. Прямые адреса не обходят блокировку. Полная защита миниатюры последних приложений требует проверки владельцем.

## Команды

Установка npm-пакетов, форматирование, npm run lint/typecheck/test:coverage, npm run build, npm run e2e, npm run case:validate. Фактические результаты перед коммитом приведены в конце записи; E2E продолжают проверяться до закрытия этапа.

## Тесты

Первый unit-прогон: 24/24, строки движка 98,23%, ветви 91,79%. Первый e2e выявил перекрытие зон при незагруженной картинке: контейнеру задано стабильное соотношение сторон, повторный прогон выполняется. Тесты не отключены; smoke M0 адаптирован к реальному меню M1.

## Проблемы и решения

Парсер markdown сначала обрезал id с цифрами и захватывал тип document вместе с шаблоном — исправлено до валидации JSON. Для Тимура объясняющий ключевой факт о сданных ключах допустим как оправдывающий: проверка не требует только supporting. Длинные ответы объединены точками с запятой, без новых сведений. Offline в браузерном e2e включается после reload: браузерная оболочка не является PWA; Android использует встроенные assets. После отключения сети игровые действия выполняются без запросов.

## Отклонения от плана

Уточнения ADR-006. React-представления M1 объединены общим хостом с защищённым выбором экранов; игровая логика из UI исключена. Изображения пока заглушки, как предусмотрено M1. Реальный ИИ не вызывался.

## Ручная проверка

MT-003 — защита при возврате; MT-008 — офлайн-прохождение. К сборке добавляется подробный сценарий MT-009. Пока сборка M1 не выдана, физическая проверка не объявляется пройденной.
