# 2026-11-11-13 — Итог M1: классическое расследование

**Этап:** M1 · **Исходный код APK:** 9f45429 · **PR:** [№2](https://github.com/dimasiksuleyman-sudo/detective_game_android/pull/2).

## Цель

Передать владельцу играемую классическую «Синюю сову» и остановиться после этапа.

## Что сделано

- Реализованы контент, валидатор, чистый движок, классические игровые экраны, документы, сохранение и защита возврата.
- Пилот содержит 23 факта, 9 улик, 3 локации с 13 хотспотами, 4 подозреваемых и 26 вопросов. Изображения — WebP-заглушки нужных размеров, подписи рисует UI.
- Игроки независимо находят улики и факты, задают вопросы, давят/сочувствуют, предъявляют улики, ломают подозреваемых; движок решает исходы и лимиты.
- Блокнот/доска/обвинение/выбывание/финал работают; версионированная партия сохраняется в IndexedDB перед подтверждением действия.
- ADR-006 фиксирует неоднозначные правила и proves. ADR-007, по замечанию владельца, убирает лишние APK на документации, сохраняя все веб-проверки и ручную полную сборку.
- Инструкции Windows и ручная очередь обновлены. API-ключи и реальный ИИ не используются; тестовая граница ИИ проверена через MockAiClient.

Парсер исходного markdown исправлен для id с цифрами; технические описания убраны из UI. Исправлены перекрытие зон до загрузки картинки и перенос последней приватной реплики на общую доску. Тесты сохранены, smoke адаптирован с заглушек к функциональному M1; ошибки ожиданий и testInfo исправлены, а не обойдены force/skip.

## Отклонения от плана

Явные уточнения ADR-006/007. Общий хост UI использует CSS Modules, правила вынесены из React. Труппу и арт заменяют предусмотренные M1 заглушки. Веб-оболочка не PWA, её загрузка с нуля без локального сервера не обещается; Android использует встроенные ресурсы.

## Как проверить владельцу

В PowerShell, из D:\Projects\detective_game_android:

```powershell
git fetch origin
git switch codex/m1-classic-game
git pull --ff-only
npm.cmd ci
npm.cmd run android:sync
```

Открыть android в Android Studio, Gradle JDK 21, выбрать TECNO CAMON 30S и Run. Проверить MT-009 в режиме полёта и MT-003 (сворачивание, повторный запуск, личная информация). Для короткого пути со спойлером: стол кабинета → сейф → обвинение Глеба, мотив хищений, статуэтка, приложить бухгалтерию. Для проверки слома — допросить Веру с давлением и предъявить ежедневник. Любой сбой прислать с шагами, раундом и игроком.

## Ручная проверка

MT-009/003 и функциональное прохождение MT-008 ожидают владельца. Голос/ключ/вибрация/датчики не объявляются реализованными. Скорость на телефоне и миниатюра последних приложений требуют реального устройства.
