## Команды и тесты

`git pull --ff-only origin main`, новая ветка, `git lfs install`. `npx tsx tools/build-pack.ts --art-only --case case-001-blue-owl`. Lint, typecheck и 136 unit (20 файлов) прошли. Валидатор обоих дел зелёный, LFS проверил 156 исходников. `npm run android:sync` — production build, verify:production и cap sync android успешно. Headless-проход 360×800 подтвердил открытие нового WebP 1024×1024 и возврат «Назад» в переулок. `npm run e2e -- --workers=2` — 118/118 за 3,7 мин на 360×800 и 412×915, без повторов. Существующий art.spec декодировал все 64 ресурса пилота, включая новый крупный план. APK/Gradle и генерация аудио не запускались.

## Проблемы и решения

В свежем main строки h-alley-end не было ни в §5.2 арт-библии, ни в ASSETS. Она добавлена по точному описанию владельца до генерации. Для полной конвертации pilot потребовалось скачать пять прежних исходников сейфа через `git lfs pull --include="art/pilot/**"`: локально оставались LFS-указатели. Новых вариантов картинки не потребовалось. Первый unit-прогон выявил прежнее жёсткое ожидание 63 ресурсов в illustrations.test.ts. Теперь ожидается 64; точное сравнение всего набора файлов с данными дела сохранено.

## Отклонения от плана

Игровых изменений нет. Новые проверки реализации не добавлялись: существующий art.spec автоматически проверяет декодирование нового WebP по manifest. Отдельное сравнение данных с main подтверждает единственное добавленное поле closeup.

## Как проверить владельцу

Дополнение к MT-025: «Синяя сова» → Обыск → Переулок у чёрного хода → Выход из переулка. Квадратный крупный план открывается, «Назад» возвращает в локацию, факты и находки прежние. Повторить в режиме полёта. Обновление — HOWTO, раздел «Крупный план выхода из переулка»; Sync и Run в Android Studio.
