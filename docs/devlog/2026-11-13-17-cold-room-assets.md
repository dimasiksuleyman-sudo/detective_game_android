## Команды

Исходная ветка создана от свежего `origin/main`, выполнены `git lfs install` и `npm ci`. Для проверки существующих сценариев установлен Chromium командой `npx playwright install chromium`.

Штатный конвертер работает **без `case.json`**. Использованы размеры из таблицы дела и `quality: 80` для всех файлов, включая предмет. PNG сохраняются в исходном разрешении генератора (1024×1536, 1536×1024, квадраты 1254×1254); реальные размеры записаны в manifest. Ресайз штатного конвертера: `sharp(source).rotate().resize(width, height, { fit: 'fill' }).webp({ quality: 80 })`. Ручная замена конвертера не понадобилась.

```bash
npx tsx tools/build-pack.ts --art-only --case case-003-cold-room
npm run lint
npm run typecheck
npm test
npm run lfs:check
npm run e2e
```

После экспорта дополнительно проверены декодирование, формат и размеры всех 31 WebP через `sharp.metadata()`; у предмета — `hasAlpha: true` и минимальная альфа 0. Дополнительно все 31 WebP декодированы настоящим Chromium через `Image.decode()` с проверкой `naturalWidth/naturalHeight`. В репозиторий проверочные скрипты не добавлялись.

## Проблемы и решения

- Генератор нарисовал аналоговые весы и круглый замок сейфа в локации цеха. Референсная правка заменила их цифровым табло без цифр и колёсиками без маркировки, сохранив расположение объектов.
- В первом кадре из кабины грузовик дублировался за стеклом. Правкой убран внешний дубликат, сохранены торпеда, документы и дождь.
- В реконструкции исправлены дублирование Павла снаружи, ошибочная сторона петель и инструмент: пломбиратор с круглыми матрицами во втором кадре, бокорезы для проволоки в третьем. Живой Павел за непрозрачной дверью показан отдельной комиксной вставкой без текста.
- Мастер Семёна выбран из трёх вариантов; сохранён только третий. Все пять эмоций — отдельные последовательные правки именно этого neutral, не предыдущей эмоции. При визуальной сверке сохраняются лицо, волосы, кепка, свитер и свет; заметного дрейфа лица нет. Павел neutral создан по его изображению в первом кадре реконструкции; Маргарита — по существующему neutral a05-olga.
- Отбракованные исходники не включаются в git; в prompts записываются правки выбранных изображений.
