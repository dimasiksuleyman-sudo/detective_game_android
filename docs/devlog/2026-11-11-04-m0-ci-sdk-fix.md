## Проблемы и решения

- JRE без javac → полный Temurin JDK 21.0.13.
- CA прокси отсутствует в новом JDK → системный truststore, TLS остаётся включён.
- В CI отсутствует старый SDK-пакет tools → исключён из списка установки; не имеет отношения к папке tools/ проекта.
- Шаблон Windows Wrapper содержит CRLF → .gitattributes нормализует содержимое в git и сохраняет CRLF при checkout на Windows.
