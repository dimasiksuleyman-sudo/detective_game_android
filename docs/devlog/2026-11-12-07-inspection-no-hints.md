# 2026-11-12-07 — Самостоятельное обнаружение без подсказок

**Этап:** планирование M3, уточнение владельца.

## Цель

Зафиксировать ответ владельца: в point-and-click не должно быть прямых подсказок.

## Что сделано

ADR-012 переведён в принятые решения, реализация по-прежнему не начата. Факт о сколе выдаётся после самостоятельного нажатия на деталь. До находки запрещены раскрывающие подписи, маркеры/подсветка, текст в описании/блокноте и преждевременные ответы ИИ/реакции предъявления. Нейтральные инструкции жестов и увеличение допустимы, автоматическое раскрытие деталей исключено. Закрыт открытый вопрос в STATUS.

## Изменённые файлы

ADR-012, геймдизайн, roadmap, STATUS, HOWTO, MT-012 — согласованные правила и статус доступности; INDEX и эта запись — журнал.

## Команды

Чтение документов; форматирование; npm run lint, npm run typecheck, npm test перед коммитом.

## Тесты

Изменена только документация; код не менялся, APK и дополнительные e2e не нужны. При реализации потребуются проверки отсутствия преждевременного раскрытия, одноразового открытия факта и сохранения прогресса. Эти тесты пока не реализованы.

## Проблемы и решения

Прежнее предложение допускало дополнительный осмотр без влияния на факт и кнопку осмотра. Уточнение владельца исключило этот вариант: игрок ищет сам; доступность достигается увеличением и удобной невидимой областью попадания.

## Отклонения от плана

Уточнение принятого ADR-012. Схема дела и текущая выдача фактов в коде не изменены; миграцию потребуется подготовить при реализации.

## Ручная проверка

MT-012 дополнен проверкой отсутствия прямых подсказок во всех каналах и открытия факта только после находки. Доступен после реализации, сейчас не проверять.

## Следующий шаг

При реализации обновить движок, формат дела/валидатор и сохранения, убрать преждевременные раскрытия. Текущая проверка M2 продолжается отдельно.
