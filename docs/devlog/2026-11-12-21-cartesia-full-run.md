## Тесты

Платная генерация остаётся отдельным ручным действием по разрешению владельца. Unit/e2e не вызывают Cartesia. Исходная проба 3,92 с уже оценена владельцем. Медиаплеер проверяется следующим шагом, физических проверок нового UI сейчас не просим.

## Проблемы и решения

Прямое скачивание Azure-артефакта недоступно облачному агенту. Для игровых ресурсов выбран нормальный путь доставки через коммит MP3 в рабочую ветку; это одновременно делает ресурсы доступными локальной сборке владельца. Ничего не сливается в основную ветку.
