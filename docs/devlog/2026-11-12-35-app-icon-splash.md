# 2026-11-12-35 — Иконка приложения, сплэш и прокрутка обыска

**Этап:** M4 / оформление и QA. **Ветка:** feature/app-icon-splash от main da942db. Один PR в main; APK не собирается (ADR-024).

## Цель

Заменить стандартные ресурсы Capacitor своей лупой с отражением одной оранжевой лампы, подготовить магазины и управлять окончанием заставки по готовности приложения. По уточнению владельца устранить невозможность прокрутить обыск к нижним кнопкам, сохранив «Назад» внизу.

## Что сделано

- Мастер, передний слой, монохромный слой и сцена магазина созданы встроенным image_gen. Форматы подготовлены техническим ресайзом/композитом; фон #1E2A33 однотонный. Шум alpha ниже 9 убран, содержимое слоёв вписано в центральный круг 590 px; это меньше 66/108 от 1024. Monochrome — белое кольцо/ручка, без цветной лампы. Отбракованный заполненный силуэт не сохранён в git.
- Восемь выбранных PNG в art/app и art/store — Git LFS. Master/foreground/background/monochrome 1024²; splash и splash-dark 2732²; магазинный icon 512² RGBA с alpha=255, без скругления; feature 1024×500 без текста. Магазинные файлы не входят в APK.
- Закреплены @capacitor/assets 4.0.0 и @capacitor/splash-screen 8.0.2. Пять входов копируются в игнорируемый assets/, стандартный генератор создаёт Android-плотности; общий дополняющий скрипт создаёт monochrome, запускную иконку и XML. Ручных PNG-правок в папках нет. Все шесть плотностей, ic_launcher_round и adaptive-icon заменены. Дополнительный inset генератора убран из XML: поля уже заданы в foreground.
- Android 12+ — системный сплэш с прозрачной лупой на #12181D. Legacy PNG — тот же фон, мотив по центру меньше четверти ширины. LaunchAutoHide=false, fade=0; платформенная обёртка вызывает hide после ready из загрузки сохранения, включая обработанную ошибку чтения. Таймера задержки нет. Реальный Android-рендер проверит владелец.
- Непрокручиваемую локацию вызывал touch-action: pinch-zoom. Теперь pan-y pinch-zoom разрешает свайп страницы по картинке, сохраняя увеличение. Отступы берут максимум env(safe-area-inset-*) и переменных SystemBars Capacitor 8.6; снизу добавлен ещё 1rem. Кнопки по последнему уточнению владельца не переносятся.
- Приложение 0.3.4 / code8. Партия, appId и формат сохранения не менялись. ASSETS, арт-библия, ADR-029, STATUS, HOWTO, CHANGELOG и MT-022 обновлены.

## Проблемы и решения

- Image_gen отдаёт PNG 1254²; исходники нормализованы до заказанных размеров, без изменения пропорций предмета. Прозрачность/безопасный круг проверяются пикселями упакованного foreground.
- @capacitor/assets не создаёт monochrome и добавляет inset уже подготовленным слоям. Один воспроизводимый постпроцессор записывает нужный XML и маску, а не ручные правки плотностей.
- В первоначальном touch-тесте финальная подпись счётчика была неточной («Использовано» вместо «Использовано действий»). Исправлен селектор; прокрутка/доступность кнопок до него проходили на обоих размерах. Кнопки остались на местах по уточнению владельца.
- Браузер не подтверждает холодный старт/темы лаунчера; это отдельный MT-пакет, не препятствие для PR.
