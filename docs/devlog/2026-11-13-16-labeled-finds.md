# 2026-11-13-16 — Подписанные находки и ещё одна цепочка

**Этап:** M3/M4 по прогулке владельца по «Номеру семь». **Версия:** 0.4.6 / code 16.

## Цель

Замечания владельца после установки 0.4.5: (1) некоторые находки при обыске не подписаны — непонятно, что найдено; (2) на кадре балконной двери видна входная дверь с цепочкой.

## Что сделано

- **Диагностика сборки:** у владельца сначала стояла старая сборка; хеши файлов в проекте и в `android/…/assets` совпали с новыми картинками — после Clean/Run показалась новая версия.
- **Подписанные находки:** у зон без улики (только факт) экран показывал «Найденная улика» и картинку без подписи. Теперь заголовок — название зоны, под картинкой — описание зоны и «В блокнот добавлено: …» со списком фактов. У зон с уликой описание тоже видно (кроме предметов с осмотром, где оно уже показывается).
- **Проверка всех 22 крупных планов «Номера семь» на цепочку:** она осталась только на `h-balcony-door` — этот кадр оказался почти копией старого вида номера. Отмечен в ASSETS на перерисовку агенту.
- **Ампула:** на картинке она лежит на полу у переполненной урны среди бумаг, а текст говорил «в урне» — текст зоны и факта приведены к картинке (библия обновлена).
- e2e: находка «Чёрный ход» в «Сове» подписана, есть «В блокнот добавлено».
