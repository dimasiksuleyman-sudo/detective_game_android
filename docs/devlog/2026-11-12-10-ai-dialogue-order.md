# 2026-11-12-10 — Приоритет ИИ-вопроса и продолжение офлайн-проверки

**Этап:** M2, сбор правок владельца.

## Цель

Записать желаемый порядок управления допросом и уточнить результат проверки без сети.

## Что сделано

Владелец просит в ИИ-режиме показывать свободный вопрос первым, а заранее написанные офлайн-вопросы ниже в свёрнутом раскрывающемся списке. Требование добавлено в ADR-014 и очередь пакета исправлений; код не менялся. После завершения предыдущего хода кнопка ИИ активна даже без сети. Это согласуется с отсутствием проверки сети в условии disabled; сетевая ошибка и сохранение реплики ещё не проверены.

## Изменённые файлы

ADR-014 — порядок UI; геймдизайн — требование; STATUS — очередь; HOWTO — доступность; MANUAL-TEST-QUEUE — результат и будущая проверка; INDEX и эта запись — журнал.

## Команды

Форматирование документов; npm run lint, npm run typecheck, npm test перед коммитом.

## Тесты

Наблюдение владельца на TECNO CAMON 30S / Android 16: на новом ходе кнопка активна без сети. Не считается успешным выполнением сценария сетевой ошибки. UI-перестановка пока не реализована и не тестировалась.

## Проблемы и решения

Офлайн-вопросы сейчас занимают место раньше свободного ввода, отвлекая от выбранного режима. Принято переместить их в свёрнутый список ниже ИИ-формы, сохранив их доступность и правила расхода реплик.

## Отклонения от плана

Уточнение UI по просьбе владельца — ADR-014; в классическом режиме вопросы сохраняют приоритет.

## Ручная проверка

Следующий один шаг: отправить вопрос при выключенном интернете и сообщить ошибку и изменение счётчика реплик. После реализации UI проверить его порядок, раскрытие списка и работу без сети.

## Следующий шаг

Продолжать сбор ошибок без немедленного исправления; затем внести согласованный пакет.
