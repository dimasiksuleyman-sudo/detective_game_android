# 2026-11-11-08 — Приёмка M0 на телефоне владельца

**Этап:** M0 · **Пункт roadmap:** установка на телефон и закрытие этапа · **Коммит:** эта запись сопровождает ручную приёмку.

## Цель

Дополнить первый результат ручного запуска моделью устройства и проверкой без сети.

## Что сделано

- Владелец указал устройство: «Техно камон 30s. андроид 16»; записано как TECNO CAMON 30S / Android 16.
- Владелец сообщил: «В режиме полёта все проверки пройдены». Вместе с предыдущим сообщением о запуске и всех экранах это подтверждает ручную приёмку каркаса M0.
- MT-001 закрыт; MT-002 отмечен пройденным по общему сообщению владельца с явным ограничением: численные времена запуска не предоставлены, измеренную скорость <3 с не утверждаем.
- M0 отмечен выполненным в STATUS. Проверки последующих этапов не затронуты, M1 не начат.

## Изменённые файлы

- docs/MANUAL-TEST-QUEUE.md — устройство, подтверждение владельца, результаты MT-001/002 и пределы измерений.
- docs/STATUS.md — закрытие M0, оставшиеся вопросы и следующий этап.
- docs/devlog/INDEX.md и эта запись — журнал приёмки.

## Команды

Форматирование изменённых документов; npm run lint, npm run typecheck, npm test перед коммитом; git commit и git push.

## Тесты

Ручные результаты сообщены владельцем, не получены агентом на устройстве. Lint/typecheck и 2 unit-теста проверяются перед коммитом. Исполняемый код не менялся, локальная пересборка APK и повтор e2e не нужны; CI запускается отправкой коммита.

## Проблемы и решения

Точные времена запуска, RAM и версия WebView не сообщены. Они не выдуманы; ограничение численных измерений сохранено в STATUS и очереди. Подтверждение относится к существующему каркасу, а не к игровым механикам будущих этапов.

## Отклонения от плана

Нет. Нового архитектурного решения нет; ADR не требуется.

## Как проверить владельцу

M0 принят по сообщённым результатам. Дополнительно можно прислать три времени холодного запуска. Для будущей игры отдельные проверки начнутся на M1.

## Ручная проверка

MT-001 ✅; MT-002 ✅ по сообщению владельца, без численных замеров. MT-003–008 ждут реализации.
