# 2026-11-12-04 — Исправление мелового контура

**Этап:** подготовка M3, замечание владельца к кабинету.

## Цель

Исправить анатомически неверный меловой контур с отсутствующими конечностями.

## Что сделано

Через image_gen отредактирован исходный кабинет. Контур заменён на целый силуэт: голова, туловище, две различимые руки с кистями, две ноги со ступнями. Он помещён на открытом участке пола. Новый оригинал сохранён в art/pilot/l-office.png; приложение пока использует заглушки. Стоковое изображение владельца служило ориентиром формы, не переносилось в ресурс.

## Изменённые файлы

art/pilot/l-office.png — исправленная иллюстрация; README ресурса, STATUS и INDEX — отметка исправления; эта запись — журнал.

## Команды

image_gen с локальным оригиналом кабинета, копирование результата; npm run lint, npm run typecheck, npm test перед коммитом.

## Тесты

Визуально проверено наличие четырёх конечностей и двух ступней, отсутствие перекрытия столом. Изменений кода нет; APK не собирается. Автоматические проверки перед коммитом обязательны, физическая проверка после подключения остаётся MT-011.

## Проблемы и решения

Первая генерация исказила силуэт. Исправление выполнено точечной правкой с явным требованием двух рук и двух ног. Другие части сцены сохранены насколько позволяет генератор.

## Отклонения от плана

Новых решений нет; генерация по ADR-011.

## Ручная проверка

Оценить исправленный контур в чате. MT-011 после подключения остаётся открытым.

## Следующий шаг

Продолжить подготовку остальных ресурсов после оценки владельцем.
