# 2026-11-12-19 — Выбор фраз и подготовка пробы Cartesia

**Этап:** M3, необязательное предварительное аудио по запросу владельца.

## Цель

Выбрать подходящие тексты, подготовить безопасный ручной генератор и одну короткую пробу.

## Что сделано

Составлены NARRATION-PLAN и манифест девяти фраз: проба + восемь основных. Скрипт читает case.json, выдаёт offline --list, GET голосов, одну пробу либо явно запрошенный полный набор. Ключ в облачной сессии отсутствует. Пользователь не видит настройки окружения, поэтому добавил Repository Secret CARTESIA_API_KEY и подтвердил готовность. Подготовлен workflow только для явно помеченного PR. Проба ещё ожидает запуска; отсутствие ключа локально останавливает скрипт до запросов.

## Изменённые файлы

content/narration/plan.json — источники текстов; tools/generate-narration.py — генератор; .github/workflows/cartesia-sample.yml — ручная проба с секретом; NARRATION-PLAN/ADR-017 — решения; STATUS/HOWTO/очередь/INDEX и эта запись — состояние.

## Команды

Чтение официальной документации Cartesia; проверка синтаксиса Python через compile; --list без сети; --sample --allow-paid без ключа завершился кодом 2 до запросов. gh secret list вернул 403 из-за ограничений интеграции; значение секрета не запрашивалось и не выводилось. Далее обязательные lint/typecheck/unit, commit/PR и ручная метка для одной пробы по разрешению владельца.

## Тесты

Обычные unit/e2e по-прежнему только MockAiClient, платный генератор не включён в них. Нет изменений приложения, дополнительный APK/e2e для отдельного скрипта не нужен. Синтаксис и список фраз проверяются локально, реальная проба — отдельный ручной запуск. Результат генерации будет записан отдельным шагом.

## Проблемы и решения

Локальный env ПК невидим облачному агенту; настроек окружения у владельца нет. Выбран секрет GitHub Actions. Для нового workflow, отсутствующего в default branch, используется явная метка PR вместо зависимости от workflow_dispatch в основной ветке. Ничего не сливается автоматически.

## Отклонения от плана

ADR-017 уточняет ADR-015 по прямому разрешению владельца. Новые платные автотесты не вводятся.

## Ручная проверка

MT-013: прослушивание русского голоса/имён/времени и отсутствие раскрытия личных данных после будущего подключения. Сейчас только оценка короткой пробы; воспроизведения в игре пока нет.

## Следующий шаг

После успешного запуска получить WAV и безопасный отчёт, предложить владельцу прослушать одну пробу. Полный набор пока не генерировать.
