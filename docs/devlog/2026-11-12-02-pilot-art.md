# 2026-11-12-02 — Генерация иллюстраций пилота

**Этап:** подготовка арта M3 по отдельной просьбе владельца; проверка M2 продолжается владельцем.

## Цель

Подготовить обложку и три основные локации «Синей совы» по арт-библии.

## Что сделано

Прочитаны требования docs/05-art-bible.md. Выбраны отдельные вертикальные иллюстрации: обложка, зал, кабинет, переулок. Генерация через встроенный image_gen; ключ aitunnel не используется. Иллюстрации выдаются в чат; игровые ресурсы пока не заменяются.

## Изменённые файлы

Эта запись и INDEX — журнал; STATUS — текущая подготовка; HOWTO — порядок дальнейшей работы; MANUAL-TEST-QUEUE — будущая проверка визуальных объектов. ADR-011 — источник арта.

## Команды

Чтение арт-библии, проверка git; генерация изображений по STYLE_CORE.

## Тесты

Изменений кода нет. Перед коммитом — lint, typecheck, unit. Приёмка стиля — по результатам генерации. Android APK для отдельно выданных изображений не собирается.

## Проблемы и решения

Новые изображения не должны мешать текущей проверке M2: подготовка ведётся в отдельной ветке codex/pilot-art. Встроенные заглушки остаются до подготовки размеров, координат хотспотов и подключения арта.

## Отклонения от плана

Владелец попросил агента сгенерировать картинки вместо предусмотренной генерации владельцем — ADR-011.

## Ручная проверка

После подключения: MT-011. Сейчас оценить стиль выданных в чате изображений.
