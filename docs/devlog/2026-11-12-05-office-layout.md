# 2026-11-12-05 — Ориентация стола и масштаб награды

**Этап:** подготовка M3, исправления по замечанию владельца.

## Цель

Показать кабинет глазами входящего детектива: хозяин сидит за столом лицом ко входу, ящики обращены к хозяину. Уменьшить непропорционально большую статуэтку.

## Что сделано

Отредактирован кабинет через image_gen. Сторона стола, обращённая к зрителю, теперь закрыта сплошной деревянной панелью без ящиков, ручек и ниши для ног. Статуэтка уменьшена примерно втрое, до визуального масштаба небольшой настольной награды. Результат сохранён в art/pilot/l-office.png и выдан в чат.

## Изменённые файлы

art/pilot/l-office.png — обновлённый оригинал; README ресурса, STATUS, MANUAL-TEST-QUEUE и INDEX — замечание и результат; эта запись — журнал.

## Команды

image_gen: первая правка масштаба и перспективы, затем уточняющая правка ориентации стола. Копирование окончательного PNG. Перед коммитом: npm run lint, npm run typecheck, npm test.

## Тесты

Визуально проверены закрытая сторона стола, отсутствие видимых ящиков и ниши, уменьшенная награда, полный меловой контур. Код не менялся; APK не собирался. MT-011 после подключения остаётся открытым.

## Проблемы и решения

Сначала агент неверно понял замечание как ошибку перспективы столешницы. Владелец уточнил ориентацию: входящий должен видеть заднюю сторону стола. Первая промежуточная генерация с ящиками не принята; в репозиторий сохранена следующая версия с закрытой панелью.

## Отклонения от плана

Новых решений нет, ADR-011.
