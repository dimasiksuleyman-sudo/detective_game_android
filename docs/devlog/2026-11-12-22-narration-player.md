# 2026-11-12-22 — Полный набор и офлайн-проигрыватель

**Этап:** M3, реализация ADR-018.

## Цель

Подключить утверждённую озвучку к разрешённым экранам без автоматического раскрытия информации.

## Что сделано

Ручной job 43208838122 успешен, сгенерированы восемь дорожек Sergei: брифинг, три существующие подсказки Шефа, три подписи реконструкции и итоговое объяснение. MP3 64 kbps mono: 747032 байта, суммарно 92,8 с. Исходные WAV+JSON в артефакте cartesia-full-originals (13939841736), игровые ресурсы сохранены коммитом 92b5820. Новых подсказок не добавлено. Один голос используется и для существующих подсказок Шефа.

Проигрыватель запускается только явно, preload=none, с обычными controls. Платформенная обёртка останавливает предыдущую дорожку, сбрасывает звук при сворачивании/уходе. Дорожка доступна только при точном совпадении текста с манифестом; старое аудио не озвучивает изменённую фразу. Финальные controls рендерятся только в завершённой партии, подсказка — только уже показанная движком. Текст остаётся доступен при ошибке звука. Из брифинга исключена фиксированная фраза про восемь раундов, выбранное число показывается отдельно.

## Изменённые файлы

STATUS/HOWTO/NARRATION-PLAN/очередь/INDEX и эта запись — результат.

## Команды

Ручной cartesia-full, git pull --ff-only после коммита ресурсов; локальная проверка хешей/размеров. lint/typecheck/unit, валидатор дела, e2e, production build и android:sync — после реализации. Платная генерация не входит в эти проверки.

## Тесты

Добавлены unit взаимного исключения дорожек, фоновой остановки/очистки, несовпадения текста и целостности MP3. E2E проверяет явный старт брифинга, отсутствие autoplay/ранних финальных записей, остановку на сворачивании и при уходе, один активный трек на финале. Результат полного прогона фиксируется после завершения. Качество полного текста на слух и звук на устройстве ещё требуют MT-013; одобрена только исходная короткая проба.

## Проблемы и решения

Исходный восьмираундовый текст не подходит к выбору 6/10: число удалено из статичной дорожки и вынесено в отдельную текстовую строку экрана. Личные улики не озвучиваются, чтобы не раскрывать их участникам. Новых native-зависимостей нет, воспроизведение WebView через платформенную обёртку.

## Отклонения от плана

ADR-018; sidecar audio/manifest.json пока только для встроенного дела, схема case.json/сохранения не меняется. Формат скачиваемых паков уточняется в M5.

## Ручная проверка

MT-013: произношение имён/времени, запуск/пауза/перемотка, офлайн и остановка при Home/блокировке/передаче, динамик/гарнитура. Точные шаги в очереди; владелец ранее отложил проверки, сейчас не просим повторять автоматизируемые сценарии.

## Следующий шаг

Завершить автоматические проверки и выдать рабочую ветку с озвучкой, затем продолжать оставшиеся задачи M3.

При первом e2e-прогоне 24 прежних сценария прошли; новый сценарий упал на выборе раундов из-за слишком строгого getByLabel для вложенного select. Заменён на доступную роль combobox с точным именем; две проверки воспроизведения после этого успешны. Один пробный запуск пересёкся с ещё завершающимся сервером и остановился из-за занятого порта; итоговый полный прогон выполняется последовательно. Исторические снимки M3 восстановлены, новые пишутся в assets/narration/.
