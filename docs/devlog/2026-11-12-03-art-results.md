# 2026-11-12-03 — Четыре готовые иллюстрации

**Этап:** подготовка M3 по просьбе владельца.

## Цель

Сохранить результаты генерации для последующего подключения в игру.

## Что сделано

Сгенерированы и выданы в чат четыре отдельные вертикальные картинки: обложка, зал, кабинет, переулок. Оригиналы скопированы в art/pilot, игровые заглушки не заменены. Размер каждого PNG 1024×1536. На локациях предусмотрены предметы осмотра; координаты предстоит адаптировать при подключении.

## Изменённые файлы

art/pilot/cover.png, l-hall.png, l-office.png, l-alley.png — оригиналы; art/pilot/README.md — происхождение и назначение; INDEX и STATUS — результат генерации; эта запись — журнал.

## Команды

image_gen: четыре промпта со STYLE_CORE, без ключа aitunnel. Копирование оригиналов и чтение размеров через Pillow. Перед коммитом: npm run lint, npm run typecheck, npm test.

## Тесты

Проверены наличие четырёх файлов и размеры. Код не менялся, APK не собирался. Ранее перед подготовительным коммитом lint/typecheck и 69 unit успешны; перед сохранением ресурсов повторяются обязательные проверки. Стиль и соответствие зон требуют визуальной приёмки; картинки не объявляются полностью подключённым артом M3.

## Проблемы и решения

Генерация не сохраняет прежние координаты зон: при интеграции надо привязать зоны к новым предметам. Сначала сохраняем отдельные оригиналы, чтобы не мешать проверке M2.

## Отклонения от плана

ADR-011: картинки по просьбе владельца генерирует агент.

## Ручная проверка

Оценить изображения в чате; после подключения выполнить MT-011. Реальная загрузка и производительность телефона пока не проверены.

## Следующий шаг

Подготовка портретов с согласованными эмоциями, крупных планов и улик; интеграция — отдельная работа M3.
