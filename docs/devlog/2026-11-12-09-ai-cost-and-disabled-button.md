# 2026-11-12-09 — Стоимость по кабинету провайдера и серая кнопка

**Этап:** M2, ручная проверка владельца.

## Цель

Уточнить доказательство стоимости и не засчитать заблокированную кнопку за проверку сетевой ошибки.

## Что сделано

Владелец предоставил скриншот активности aitunnel: 3 запроса, расход 0,03 ₽, средняя цена 0,01 ₽, около 2,2 тыс. токенов. Это фактическая небольшая выборка, не полный бенчмарк. При выключенном интернете владелец наблюдает серую кнопку «Спросить ИИ», нажать нельзя.

## Изменённые файлы

STATUS, MANUAL-TEST-QUEUE и INDEX — уточнение результата; эта запись — журнал. Код не менялся.

## Команды

Чтение условий блокировки в src/screens/GameApp.tsx; npm run lint, npm run typecheck, npm test перед коммитом.

## Тесты

Кнопка блокируется при пустом вопросе, трёх использованных репликах, блокировке подозреваемого или ожидании операции. Прямой проверки наличия сети в этом условии нет. По одному наблюдению причина не определена. Ошибка сетевого запроса и сохранение квоты пока не проверены.

## Проблемы и решения

Возможно, перед отключением сети уже использованы три реплики; также после отправки поле очищается. Сначала проверить на свежем ходе с непустым вопросом, не предполагая автоматическую блокировку по сети.

## Отклонения от плана

Нет. Исправления по-прежнему собираются одним пакетом.

## Ручная проверка

При выключенном интернете перейти на новый ход, открыть допрос и набрать непустой вопрос; сообщить, стала ли кнопка активной. Сам сетевой вызов — следующий шаг после подтверждения.

## Следующий шаг

Продолжить проверку по одному действию с подтверждением владельца.
