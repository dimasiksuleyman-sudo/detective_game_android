# 2026-11-12-15 — Удаление ключа подтверждено владельцем

**Этап:** M2, ручная проверка.

## Цель

Зафиксировать результат удаления ключа с перезапуском приложения.

## Что сделано

После инструкции удалить ключ, перезапустить и проверить настройки владелец сообщил: «Ключ исчез». Подтверждено исчезновение сохранённого ключа в интерфейсе после удаления/перезапуска на TECNO CAMON 30S / Android 16. Доступность ИИ для новой партии и классики после удаления пока проверяется отдельно.

## Изменённые файлы

STATUS, MANUAL-TEST-QUEUE, INDEX и эта запись — результат проверки; код не менялся.

## Команды

Форматирование; npm run lint, npm run typecheck, npm test перед коммитом.

## Тесты

Физически подтверждён владельцем результат удаления после перезапуска. Это не является инструментальной проверкой содержимого Keystore/Logcat или резервных копий. APK не собирается.

## Проблемы и решения

Новых ошибок не сообщено; не закрываем целиком MT-004/010 по одному результату.

## Отклонения от плана

Нет.

## Ручная проверка

Следующий шаг: открыть настройку новой партии без ключа и проверить, что режим ИИ недоступен. Не создавать новую партию поверх нужного сохранения без необходимости; достаточно посмотреть выбор режима.

## Следующий шаг

Продолжить по одному действию с подтверждением владельца; пакет исправлений остаётся отложенным до завершения сбора.
