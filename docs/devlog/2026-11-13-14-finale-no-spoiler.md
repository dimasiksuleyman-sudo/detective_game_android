# 2026-11-13-14 — Финал без спойлера и концепции дела № 3

**Этап:** M4 / UX по замечанию владельца; подготовка дела № 3. **Ветка:** claude/lucid-wozniak-3iu7wi от main. **Версия:** 0.4.4 / code 14.

## Цель

Владелец прошёл «Сову» — понравилось. Уточнение: при ложном обвинении не показывать финал сразу, а спросить — вдруг игроки захотят сыграть ещё и докопаться сами. Затем — шаг 1 ранбука для дела № 3.

## Что сделано

- Экран итога: если победителей нет, сначала «Дело не раскрыто» и вопрос «Показать, как всё было?» — «Да, показать разгадку» / «Нет, сыграть ещё раз». «Нет» открывает настройку новой партии того же дела. При победе финал — как раньше.
- Два e2e-сценария в `turn-rules.spec.ts`: разгадка скрыта без согласия; «нет» → новая партия; «да» → «Как всё было».
- `docs/cases/case-003-concepts.md`: три концепции дела № 3 с учётом всех уроков (цепочка, мутный след из существующей неоднозначности, без совпадений-близнецов, наблюдения вместо выводов) и рекомендация.
- `docs/cases/case-003-cold-room.md`: полная библия дела № 3 «Холодная камера» (схема v4): правда, хронология, 28 фактов, 3 локации, сейф 0418, 3 детали, 12 улик, 4 подозреваемых с тайнами и ступенями признания Маргариты, подсказки Шефа, объяснение, список картинок с промптами для агента.
- Геймдизайн §2.9, дополнение ADR-034, CHANGELOG, HOWTO, MT-028, STATUS.
