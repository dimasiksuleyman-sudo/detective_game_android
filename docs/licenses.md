# Лицензии шрифтов

Шрифты встроены в приложение, загружаются из APK/локального сервера и не обращаются к Google Fonts. Файлы не изменялись.

| Шрифт                                 | Назначение                        | Источник                  | Версия | Лицензия                     |
| ------------------------------------- | --------------------------------- | ------------------------- | ------ | ---------------------------- |
| PT Mono 400, кириллица и латиница     | Заголовки, стиль печатной машинки | npm `@fontsource/pt-mono` | 5.3.0  | SIL OFL 1.1, ParaType © 2010 |
| PT Sans 400/700, кириллица и латиница | Основной текст                    | npm `@fontsource/pt-sans` | 5.3.0  | SIL OFL 1.1, ParaType © 2009 |

Полные неизменённые тексты лицензий распространяются вместе с APK: [PT Mono](../public/licenses/pt-mono-OFL.txt), [PT Sans](../public/licenses/pt-sans-OFL.txt). Не продавать шрифты отдельно, сохранять уведомления правообладателей и лицензию. Зависимости кода и их версии зафиксированы в package-lock.json; перед публичным релизом нужен общий список лицензий зависимостей.
