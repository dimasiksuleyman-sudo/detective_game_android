# 00. Обзор проекта

## Одной фразой
Нуарная детективная party-игра для 1–4 игроков на одном Android-телефоне: каждый ведёт своё расследование, допрашивает ИИ-подозреваемых и пытается первым раскрыть дело.

## Ключевые принципы
1. **Один телефон, тайная информация.** У каждого игрока свой блокнот с уликами; передача телефона закрыта экраном-заглушкой.
2. **ИИ — голос, а не мозг.** Правила, улики, раскрытие фактов — детерминированный движок. LLM только отыгрывает персонажа и «озвучивает» то, что движок разрешил. Поэтому ИИ не может испортить дело или проговориться.
3. **Офлайн-первым.** Без сети и без ключа игра полностью проходима (допрос вопросами из списка). ИИ открывает свободные вопросы и голосовой ввод.
4. **Свой ключ (BYOK) на старте.** Игрок вставляет свой ключ aitunnel.ru. Подписка с нашим ключом — позже, если будет спрос (см. ADR-002).
5. **Контент как данные.** Дело = JSON + картинки. Новые дела скачиваются паками с нашего сервера, без обновления APK. Цель — новое дело раз в ~3 дня.
6. **Переиспользуемые ассеты.** «Труппа актёров» и пул локаций: в новом деле нужны только 15–20 новых картинок, а не 55.

## Что входит в первую публичную версию (v1.0)
- Режим «Комната допросов» (соревновательный, 2–4 игрока) + одиночный режим (1 игрок).
- 2–3 встроенных дела (пилот — «Синяя сова»), загрузка новых паков с сервера.
- Допрос: офлайн (список вопросов) и ИИ (свободный текст/голос) с ключом пользователя.
- Предъявление улик, шкала стресса, «слом» подозреваемого.
- Обыск локаций с кликабельными зонами, крупные планы, улики-документы, отрисованные кодом.
- Обвинение (виновный + мотив + способ + ключевые улики), финальная реконструкция.
- Настройки: ключ, проверка ключа, баланс, модель (расширенные), размер текста, звук, вибрация.

## Что НЕ входит в v1.0 (позже)
- Режимы «Один из нас», «Бюро», «Крот» — после проверки ядра.
- Подписка и оплата (Google Play Billing / RuStore) — этап M7.
- iOS, веб-версия, онлайн-мультиплеер.
- Генерация картинок на лету.
- Озвучка персонажей (TTS) — возможно позже.

## Целевая платформа
- Android 8.0+ (API 26+), портретная ориентация, телефоны от 5.5".
- Должно плавно работать на бюджетных устройствах (2–3 ГБ ОЗУ).
- Язык: русский (строки вынесены для будущей локализации).
