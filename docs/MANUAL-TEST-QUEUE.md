# Очередь ручных проверок на телефоне

_Агент добавляет пункты; владелец проверяет на реальном устройстве и отмечает результат._

Формат пункта:

```
### MT-NNN — Короткое название (этап Mx, сборка vX.Y.Z / коммит abc123)
- Устройство: (заполняет владелец — модель, версия Android)
- Шаги: 1… 2… 3…
- Ожидается: …
- Результат: ⏳ / ✅ / ❌
- Комментарий владельца: …
```
