## Кодовый сейф и подпись (ADR-028)

Актуальный пилот: schemaVersion **3**, version **4**, minAppVersion **0.3.3**. Предыдущие разделы ADR-019 описывают историю формата, а не текущую версию.

Код **1408** выводится из записи «Сейф — день рождения Совы» и даты открытия **14.08.2014** на обороте фото. Никаких цифр в ежедневнике/его факте больше нет. Валидатор моделирует оба факта как AND; при удалении любого источника бухгалтерия недостижима. Игра принимает верный ввод и без фактов: другой участник может сообщить код вслух.

Неверная попытка: «Не подходит», лёгкая тряска, без расхода действия и выдачи предметов. Первое верное открытие засчитывается как осмотр зоны кабинета; с 0.4.1 за ход можно осмотреть весь кабинет (ADR-034). Повторный просмотр и отдельные предметы бесплатны. Сейф открыт только для текущего игрока, пока остальные не введут код сами. Предметы не выдаются автоматически.

Внутри четыре области без подсветки. Бухгалтерия даёт только переводы на «Норд-Транзит». Подпись **Г. Соколов** нужно найти на развороте самому: d-ledger-signature → f-ledger-signature → условие денежного брейкпоинта Глеба (прежний порог стресса 6). Другая тайна Глеба не раскрывается этим действием.

Конверт с отказом Вере — ложный след, объясняется её долгом (f-vera-debt) и подтверждённым выступлением (f-vera-alibi). Черновик делает подозрительной наследницу Ольгу (f-olga-heir), но её гостиничное алиби (f-olga-hotel) сохраняется. Ссылки explanationFactIds показываются в финале; обнаружение предмета само не раскрывает алиби/тайну. Визитка дублирует встречу с юристом. Каноническое объяснение убийства, хронология и восемь готовых голосовых файлов не изменены; новая подсказка Шефа пока текстовая.

**Кратчайшие проверенные пути при существующих правилах обвинения:** известный код → одна зона сейфа → бухгалтерия → подпись → обвинение Глеба в хищениях со статуэткой и фактом подписи, победа в первом раунде. Самостоятельная дедукция → фото в зале → следующий ход → ежедневник и сейф в кабинете → подпись → обвинение: три зоны за два хода. Это проверка минимального пути, а не изменение требований к обвинению: достаточно одной ключевой улики/факта и правильной тройки виновный/мотив/способ.
