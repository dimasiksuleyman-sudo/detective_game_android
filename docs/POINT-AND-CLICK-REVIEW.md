# Обход экранов и места для point-and-click

**Дата:** 2026-11-12. Обход выполнен в Chromium 412×915 через реальные элементы интерфейса, без сетевых ИИ-запросов: меню → настройки/инструкция → новое дело → два игрока → передача → обыск → находки → блокнот → допрос → доска → обвинение → финал. Скриншоты до правок: docs/devlog/assets/pnc-audit/. Это проверка браузера, не физического телефона.

Для основных точек достаточно трёх уровней «комната → предмет → наблюдение», без обязательной цепочки из множества пустых нажатий.

## Найденные проблемы

1. После находки статуэтки крупный план и описание сразу сообщают про скол и орудие; факт сразу в блокноте. Это отменяет самостоятельный поиск детали. Убираем эти сведения из начального текста, переносим факт в отдельное исследование.
2. После осмотра статуэтки и повторного открытия ежедневника из блокнота рядом с ежедневником остаётся closeup пола. При открытии из блокнота нужен собственный контекст предмета.
3. «Назад» из предмета, открытого в блокноте, уводит в кабинет. Надо возвращать к источнику открытия; повторный осмотр не должен начинать новый обыск.
4. На экране находки сейчас два изображения-заглушки с повторяющимся текстом. У предмета с интерактивным осмотром будет один настоящий рисунок с увеличением.
5. Карточки доски показывают опубликованное имя, но не открывают просмотр. Записано как кандидат, без автоматического копирования улики/детали другому игроку.

## Правила реализации

Нет подсветки искомой точки, названия детали или текста о ней до обнаружения. Скол должен быть различим в рисунке при увеличении. Достаточно большая невидимая область попадания и нейтральное обучение жестам; клавиатурный фокус/доступные имена управления сохраняются, но не называют скрытый признак. Ошибочное нажатие не расходует ход. Повтор не начисляет факты/очки заново, каждый игрок открывает наблюдение самостоятельно.

Новые факты не должен заранее выдавать ИИ, реакция предъявления, описание/карточка или публикация предмета. Старые уже открытые факты не отбираем при миграции. Просмотр опубликованного предмета на доске и личное исследование — разные права.

## Повторный обход после исправлений

Сценарий двух игроков повторно пройден до победы. Снимки assets/pnc-audit-after/ сравнивались с исходными. В начальном тексте статуэтки больше нет скола/орудия; после осмотра участка появляются наблюдение и факт. При повторном открытии ежедневника остаётся только его картинка (без h-floor), возврат ведёт в блокнот. Для статуэтки теперь один интерактивный рисунок и миниатюра в блокноте. Из перечисленных кандидатов реализован этот предмет и бесплатный повторный осмотр; фото/документы/доска/предпросмотр обвинения остаются планом. Полный e2e 32/32, отдельный обход не заменяет физическую проверку попадания пальцем.
