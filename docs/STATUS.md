## Что работает

- Иконка: лупа с одной оранжевой лампой #D2691E на фоне #1E2A33. Отдельные слои foreground/background/monochrome в точном размере 108dp на всех шести плотностях (раньше были 48dp и растягивались в 2,25 раза — иконка мылилась). Обычная и круглая иконки 48dp. Содержимое в безопасном круге 66/108.
- Заставка: Android 12+ — системная иконка на #12181D, Android 8–11 — PNG с мотивом по центру. Скрывается сразу по готовности сохранения; если загрузка зависнет, страховочный таймер скрывает её через 8 секунд.
- Свайп по картинке локации прокручивает страницу к нижним кнопкам и не тратит действие. Отступы учитывают системную панель навигации.
- Ресурсы Android воспроизводятся командой `npm run assets:android` из исходников в Git LFS (`art/app`); вручную PNG не правятся.
- Сейф, подпись, документы, режимы ИИ и сохранения v3 не менялись.
