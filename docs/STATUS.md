## Что работает

- Классическая «Синяя сова» без сети и ключа: 23 факта, 9 улик, 3 локации, 13 зон, 4 подозреваемых, 26 вопросов. Партии для 1–4 игроков, лимиты, стресс/адвокат, предъявления и сломы, доска, обвинение, выбывание и финал.
- IndexedDB-сохранение, «Продолжить», удержание передачи 1 с и защита возврата через web visibility / Android App. Старые M1-сохранения получают значения по умолчанию без смены схемы дела.
- Настройки M2: маскированный ввод и вставка ключа, проверка методом баланса без генерации, удаление, обновление баланса, выбор модели и явно включаемая запасная модель. Android использует secure storage с AES-GCM/Android Keystore; web — sessionStorage с предупреждением. Физическое поведение ещё требует MT-004/010.
- Новая ИИ-партия доступна с проверенным сохранённым ключом. Свободный вопрос, тон, индикатор ожидания, безопасные сообщения ошибок, озвучивание предъявления и классическое предъявление в той же партии без сети.
- В промпт попадает только разрешённый срез одного подозреваемого и история текущего игрока. Движок решает факты и исход предъявления. Parser/guard проверяют JSON, длину, эмоции, стресс, допустимые id и признаки утечки; после неудачных попыток используется детерминированный фолбэк без расхода реплики.
- Отмена при сворачивании не применяет поздний ответ к другому ходу. Известная стоимость учитывается отдельно от игрового результата; неизвестная стоимость обозначена явно.
- Локально и в CI успешны lint/typecheck, 69 unit, валидатор, production build и проверка отсутствия тестовой подмены. Покрытие движка: 98,89% строк / 90,04% ветвей. E2E: 20/20 при 360×800 и 412×915, только MockAiClient.
- [CI исходного кода 4e23355](https://github.com/dimasiksuleyman-sudo/detective_game_android/actions/runs/43189010590) завершён успешно, включая debug APK 0.2.0 / code 3. [APK ZIP](https://github.com/dimasiksuleyman-sudo/detective_game_android/actions/runs/43189010590/artifacts/13929139414), [браузерные результаты](https://github.com/dimasiksuleyman-sudo/detective_game_android/actions/runs/43189010590/artifacts/13929378503).

## Известные проблемы и ограничения

- Реального ключа у агента нет, генерации и платного бенчмарка не было. API-id и параметры сверены с публичными источниками, фактическая доступность и качество моделей не подтверждены. `qwen3.7-flash` выбран предварительно; окончательный выбор — после бенчмарка (ADR-009).
- Guard — эвристическая защита текста, а не формальная гарантия отсутствия галлюцинаций. Канонические факты и обвинение остаются детерминированными.
- Повторы могут увеличить стоимость: до двух попыток основной модели и третья на запасной только при включённой настройке. Отмена не гарантирует отсутствие списания провайдером.
- Keystore, удаление ключа, Clipboard, Logcat, миниатюра последних приложений, производительность и полный цикл на физическом телефоне ожидают владельца. Автотесты не подтверждают эти свойства устройства.
- Изображения — цветные WebP-заглушки. Финальный арт — M3; голос, вибрация, системный «Назад» и keep-awake — M4; датчики — M6.
- Web не PWA: загрузка страницы с нуля требует работающего локального сервера. Android содержит ресурсы в APK. Защита от чтения файлов приложения/devtools не заявляется.
- Общий UI-хост GameApp пока содержит представления игровых экранов; правила изолированы в движке. Конфликт сборки instrumentation-APK всех библиотек сгенерированного Cordova-модуля из M0 остаётся отдельным ограничением; обычный debug APK успешен.

## Сборки и следующий шаг

Пользователь собирает APK локально. По ADR-007 дополнительные облачные APK нужны при изменениях Android/зависимостей/Capacitor или ручном Run workflow; документационные изменения не требуют повторной сборки. M2 добавил native-плагины, поэтому выполнен один контрольный APK.

Обновление на Windows: `git fetch origin` → `git switch codex/m2-ai-interrogation` → `git pull --ff-only` → `npm.cmd ci` → `npm.cmd run android:sync` → Gradle Sync / Run в Android Studio с JDK 21. Подробно — HOWTO. Затем на телефоне: Настройки → ИИ-допрос → Ключ aitunnel → Проверить и сохранить ключ; создать новую ИИ-партию. Перед M3 — отчёт владельца и продолжение по его команде.

## Предложение: point-and-click детали улик

ADR-012 фиксирует идею владельца: комната → статуэтка крупным планом → нажатие на скол → осмотр детали. Зоны комнат и экран находки реализованы, второй уровень деталей — нет. Идея добавлена в геймдизайн и предложения M3, код и схема не менялись.

### Решение владельца — осмотр без прямых подсказок

Вопрос закрыт: игрок самостоятельно обнаруживает скол; соответствующий факт открывается после нажатия на деталь. До находки нет раскрывающих подписей/описаний, подсветки/маркеров, автоматического раскрытия и подсказок через ИИ. Нейтральное обучение жестам и увеличение допустимы. ADR-012 принят; реализации ещё нет, прежняя сборка этим требованиям пока не соответствует. При реализации проверить выдачу фактов, реакции предъявления, данные дела и совместимость сохранений.

## Проверка M2 владельцем и пакет будущих правок

Подтверждено на TECNO CAMON 30S / Android 16: ввод/сохранение ключа, проверка баланса, осмысленные реальные ответы. Оценка владельца — около 0,01 ₽ за запрос; модель/полный бенчмарк не зафиксированы. Эти новые результаты уточняют прежние отметки отсутствия физической проверки выше; MT-004/010 ещё не пройдены целиком.

Очередь без немедленного изменения кода: явно показать сохранённый ключ после перезапуска (звёздочки/статус без раскрытия секрета); запланировать 10 ИИ-запросов на раунд игроку (ADR-013). Владелец просит собрать ошибки и исправить вместе; проверку вести по одному действию с подтверждением.

### Открытые вопросы к владельцу — квота

Согласовать сочетание новой квоты с офлайн-вопросами/предъявлениями и существующим ограничением одного подозреваемого на ход; расширение максимума с четырёх до пяти игроков; подсчёт внутренних повторов. Расчёт 5 ₽ относится к пяти игрокам, десяти раундам и 0,01 ₽ за запрос без повторов. Действующий код пока не менялся.

Уточнение по скриншоту aitunnel: 3 запроса / 0,03 ₽, средняя цена 0,01 ₽ (небольшая выборка). В режиме полёта кнопка ИИ серая; причина пока не установлена. В коде кнопка не проверяет сеть, но блокируется при пустом поле/лимите трёх реплик/блокировке подозреваемого/ожидании. Сетевая ошибка и отсутствие списания квоты ещё не подтверждены.

Дополнение пакета M2: ADR-014 — в ИИ-режиме сначала свободный вопрос, ниже свёрнутый список готовых офлайн-вопросов. Пока не реализовано. Владелец подтвердил, что после завершения хода кнопка активна и без сети; прежняя блокировка не доказывала зависимость от интернета. Ошибка при отправке без сети и сохранение квоты ещё ожидают проверки.

Дополнение проверки M2: на скриншоте владельца при отключённом интернете показана сетевая ошибка и текст о несписании реплики. Фактический счётчик и выполнение офлайн-вопроса ещё не подтверждены отдельно. В очередь добавлено устранение повторения «реплика не списана». По ADR-015 временные ошибки в дальнейшем показываются тостом; пока постоянный блок разрешён владельцем. Озвучка вступления через Cartesia.ai записана как идея, API не подключён. Открытый вопрос к владельцу на этапе реализации: выбрать голос/провайдера и условия подготовки аудио; предварительно предлагается готовая офлайн-дорожка с текстовой альтернативой.

MT-010, дополнение владельца: готовый офлайн-вопрос дал ответ при выключенном интернете. Работа офлайн-вопросов в ИИ-партии физически подтверждена; отмена, удаление/Logcat и независимая проверка счётчика после сетевой ошибки ещё открыты.

Наблюдение владельца при сворачивании до ответа ИИ: возврат в главное меню → «Продолжить» → передача игроку. Прямое раскрытие личного экрана не наблюдалось. Отсутствие позднего ответа/расхода реплики ещё не подтверждено; причина открытия меню вместо немедленной передачи не установлена. Сохранить для оценки в пакете правок.

Подтверждение владельца после возврата: ответ на прерванный сворачиванием вопрос не появился. Часть MT-010 об отсутствии позднего ответа подтверждена; игровой счётчик и расходы провайдера этим не подтверждаются.
