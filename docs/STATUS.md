## Что работает

- Реестр public/cases/*/case.json и загрузка по caseId, S03 с обложкой, названием, слоганом, сложностью и минутами. Выбор новой партии не меняет сохранённую до явного старта.
- UI, движок и ИИ используют дело партии. «Продолжить» восстанавливает его; неизвестный id вызывает ошибку без подмены и перезаписи.
- Сохранение v4, чтение v1–v4. Отсутствующий caseId у старой партии означает пилот. Прежние миграции сейфа/подписи ограничены пилотом; заметки, история, очки, признания и доска сохраняются.
- Озвучка выбирается из собственного audio/manifest.json дела по точному тексту. Отсутствующая/устаревшая запись скрывается. Готовность арта определяется по манифесту дела, труппа общая. Музыка остаётся общей.
- Замок читает 1–8 цифр из схемы, сбрасывается при смене дела/замка. У пилота прежние четыре цифры. Тестовая фикстура с тремя цифрами и вторым id включается только в e2e-сборке, production её отвергает.
- Канон пилота и утверждённая библия второго дела не менялись. Новых производственных картинок, аудио или дел нет.

- Из свежего main сохранены исправление чёткости adaptive-иконки (слои 108dp) и страховочное скрытие сплэша через восемь секунд при зависшем запуске; при нормальной загрузке он скрывается сразу. Их телефонная приёмка — MT-022; MT-021 относится к допросу.
