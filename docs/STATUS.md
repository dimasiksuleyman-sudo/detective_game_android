## Что изменилось

- Лупа с одной оранжевой настольной лампой #D2691E, фон иконки #1E2A33. Отдельные foreground/background/monochrome, все плотности Android и круглая иконка. Значимое содержимое целиком в безопасном круге 66/108. Контакт-лист: три маски × три размера × два фона; одобрение владельца пока не получено.
- Android 12+ — системная иконка на #12181D, legacy — квадратный PNG с центральным мотивом. SplashScreen.hide вызывается через платформенную обёртку после ready из чтения партии, без таймера/искусственной паузы; ошибка загрузки сохранения тоже переводит экран в готовность. Нативное отображение требует MT-021.
- @capacitor/assets 4.0.0 и SplashScreen 8.0.2 закреплены точно. Восемь исходников PNG — Git LFS, Android-ресурсы — обычные файлы. Входы assets/ воспроизводятся скриптом. Магазинные 512² и 1024×500 не входят в APK.
- По уточнению владельца «Назад» остаётся внизу. У локации исправлен touch-action: pan-y pinch-zoom; теперь свайп по картинке прокручивает страницу к нижним кнопкам. Отступы используют env и переменные SystemBars Capacitor 8.6, без двойного сложения одного inset; снизу ещё 1rem.
- Сейф, подпись, документы, режимы ИИ и сохранения v3 сохранены; ключи и данные партии не стираются. Голосовые файлы не генерировались заново.
