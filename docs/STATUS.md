- Классическое расследование «Синяя сова» без ключа: 23 факта, 9 улик, 3 локации, 13 зон, 4 подозреваемых, 26 вопросов.

- До 2 зон одной локации или 3 реплик одному подозреваемому; требования зон/вопросов, стресс/адвокат, предъявление и слом.
- Блокнот: улики, факты, заметки, хронология; публикация на общую доску, обвинение, выбывание, финальные попытки, очки и подсказки.

- Lint/typecheck успешны, unit 24/24, строки движка 98,83%, ветви 91,79%. E2E 10/10 при 360×800 и 412×915, 42 скриншота просмотрены.

## Известные проблемы и ограничения

- MT-009/003 для M1 ещё не пройдены владельцем. Приёмка M0 не подтверждает новую игру, работу App plugin и сохранения на телефоне.
- Изображения — цветные WebP с подписями, финальный арт и анимации — M3. Голос, вибрация, системная кнопка «Назад» и keep-awake — M4; датчики — M6.
- Реальный ИИ и хранение ключа не подключены. В тестах используется только MockAiClient; платных запросов не было.
- Веб-оболочка не PWA. После выключения локального сервера нельзя обещать загрузку страницы с нуля без сети; Android хранит данные и ресурсы внутри APK.
- Приватность после возврата проверена в браузере; миниатюра последних приложений Android требует MT-003. Не заявляется защита от человека, читающего файлы приложения или devtools.
- Численные времена запуска на устройстве для M1 не измерены. Ограничение test runtime сгенерированного Cordova-модуля при сборке тестовых APK всех библиотек из M0 сохраняется как отдельная задача; обычный APK собирается, instrumentation на устройстве агент не запускал.
- Общий хост GameApp содержит представления игровых экранов; логика правил вынесена в engine. Последующее разделение UI на более мелкие модули не меняет сохранение и правила.

## Сборки и следующий шаг

ADR-007 исключает лишние APK после документации/веб-правок: нативная сборка по изменениям Android или зависимостей, либо Run workflow. Остальные проверки сохраняются. Для локального обновления: git fetch origin → git switch codex/m1-classic-game → git pull --ff-only → npm.cmd ci → npm.cmd run android:sync → Run в Android Studio с JDK 21.

После отчёта M1 работа останавливается перед M2. Ручные результаты будут записаны отдельно по сообщениям владельца.
