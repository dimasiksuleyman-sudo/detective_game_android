## Исправления после QA

- Системная «Назад» через @capacitor/app и история браузера: личные экраны → хаб; хаб → подтверждение меню; меню Android → выход. Переходы replace; защитная запись истории удерживает браузер внутри приложения. S03–S05 не заменяют активную партию; START_GAME требует явного флага подтверждённой перезаписи.
- Явные возвраты: комната → локации, допрос → подозреваемые, настройка → выбор дела, настройки/правила → меню. Передача имеет кнопку меню. Финал — без раунда, «Сыграть ещё» с подтверждением и «В меню».
- Допрос: компактный портрет ≤40% высоты, единственное имя, прокручиваемый чат, вопрос на первом экране. Онлайн/Офлайн меняет ввод в той же партии; офлайн-вопросы доступны всегда. S04 — заметные кнопки режима, без ключа ИИ отключён, есть переход к настройкам.
- 31 текст восстановлен по пунктуации канона. Валидатор запрещает `; ` перед заглавной и одиночное `?.`; каноническое `?..` сохраняется. Все восемь записей озвучки соответствуют тексту игры. ADR-021 уточняет предел четырёх предложений для офлайн-признания; ИИ и обычные ответы остаются до трёх.
- DocumentRender оформляет документы по шаблону; описание не повторяется. Ответы подозреваемых только в чате, сообщения очищаются при уходе, заметки сохраняются автоматически. Пустая доска/предъявление объясняют следующий шаг, ноль действий требует подтверждения конца хода.
- Удержание передачи: запрет выделения/contextmenu и полоска 1 с. S17: нормализованные координаты, ограниченный изображением прямоугольник, копирование JSON; только dev/debug, исключён из production.
- Новые e2e-снимки — в игнорируемой `test-results/screens/`. В docs копируются только выбранные кадры отчёта.
