## Работает и проверено автоматически

- Классическая «Синяя сова»: 23 факта, 9 улик, 3 локации, 13 зон, 4 подозреваемых, 26 готовых вопросов, обыск/стресс/слом/блокнот/доска/обвинение/финал.
- 1–5 игроков с отдельными цветами, сохранение и продолжение. Три реплики одному подозреваемому за ход в обоих режимах, две зоны обыска; ошибки ИИ не расходуют реплику. Вариант десяти реплик отменён ради баланса (ADR-013).
- ИИ-настройки: ключ через Android secure storage, маска сохранённого ключа без подстановки секрета в поле, проверка/баланс/удаление. ИИ-форма перед свёрнутыми готовыми вопросами; в классике готовые вопросы открыты. Прямое соединение с aitunnel, разрешённый срез знаний, parser/guard, повторы, отмена и учёт известной/неизвестной стоимости.
- Готовая обложка и три локации WebP, суммарно 1 039 054 байта (около 1 МБ); PNG вне public и не включаются в APK. Все 13 зон перемещены на соответствующие предметы. Нет постоянных текстовых плашек поверх рисунков; доступные имена и клавиатурный фокус сохранены.
- Валидатор дела и ресурсов, lint/typecheck, 71 unit; покрытие движка 98,89% строк / 90,04% ветвей. Полный e2e 24/24 на 360×800 и 412×915, включая полный классический сценарий и MockAiClient. Production-проверка и android:sync успешны. Новые скриншоты — docs/devlog/assets/m3/.

## Что подтвердил владелец на телефоне

TECNO CAMON 30S, Android 16; WebView не сообщён.

- Ключ вставляется/сохраняется, баланс проверяется. Реальные ИИ-ответы разумны.
- Кабинет aitunnel: 3 запроса / 0,03 ₽, средняя цена 0,01 ₽ — небольшая реальная выборка, не полный бенчмарк.
- Без сети появляется понятная ошибка; готовый офлайн-вопрос даёт ответ. Независимая проверка счётчика после ошибки не сообщена.
- Сворачивание до ответа: возврат в главное меню → «Продолжить» → передача. Ответ на прерванный вопрос после возврата не появился. Причина возврата в меню вместо немедленной передачи не установлена; отсутствие оплаты провайдером не утверждается.
- После удаления/перезапуска ключ исчезает, выбор ИИ для новой партии недоступен.

## Отложенные проверки и ограничения

- **MT-014 — отложено владельцем:** маска сохранённого ключа и порядок вопросов из пакета исправлений. Новую установку на телефон владелец ещё не подтвердил; git fetch выполнен. Точные шаги в MANUAL-TEST-QUEUE.
- MT-011 — визуальное соответствие зон/компоновка арта и производительность на телефоне, тоже ждут удобного владельцу времени.
- Перезагрузка телефона с сохранённым ключом, Logcat/Keystore, миниатюра последних приложений и прочие незакрытые части MT-004/010/003 остаются открытыми. Агенты не должны заменять их автотестами или просить повторять уже проверенные игровые сценарии без новой причины.
- Портреты, крупные планы, улики, реконструкции пока заглушки. Дополнительный point-and-click «статуэтка → скол → факт» по ADR-012 ещё не реализован: сейчас факт выдаётся при обычном осмотре, как в M1. Для изменения нужны схема/движок/миграция и отсутствие преждевременного раскрытия через описания/ИИ.
- Guard эвристический, канонические факты определяет движок. Выбор основной модели предварительный, все параметры/модели не прошли полный бенчмарк. Внутренние повторы могут увеличить расходы, отмена не гарантирует отсутствия оплаты.
- Web не PWA, требует работающего сервера при загрузке с нуля; Android содержит ресурсы локально. Web-ключ — sessionStorage-заглушка с предупреждением, нативная ошибка не переводит ключ в обычное хранилище.
- Голос/вибрация/системный «Назад»/keep-awake/тосты — M4, датчики M6. Cartesia.ai только кандидат для предварительной озвучки вступления, API не подключён. Инструменты ZIP/публикации паков ещё не реализованы.

Открытый вопрос после пробы: оценить голос и произношение.

Нормализация завершена успешно в run 43207774888 без Cartesia-ключа и без нового запроса. Фактическая длительность 3,92 с, конечный WAV 345788 байт. Исправленный [артефакт cartesia-sample-repaired](https://github.com/dimasiksuleyman-sudo/detective_game_android/actions/runs/43207774888/artifacts/13940730537). Голос Sergei, одна пробная фраза.
