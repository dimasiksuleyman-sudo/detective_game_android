# План озвучки «Синей совы»

## Первая проба

«Ветрогорск, ночь с пятницы на субботу, проливной дождь» — короткое начало брифинга, 55 знаков с пунктуацией. Сначала один русский мужской голос из библиотеки Cartesia; ориентир — спокойный взрослый рассказчик без чрезмерной театральности. Без клонирования реальных людей.

## Что озвучить

| Приоритет | Тексты                                                   | Когда доступны                                                                         |
| --------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 1         | Вступление/брифинг дела                                  | Перед началом расследования, общая информация                                          |
| 2         | Три существующие подсказки Шефа                          | Только при выполнении игровых условий подсказки, без добавления новых прямых подсказок |
| 3         | Три подписи реконструкции                                | Только после завершения дела, содержат спойлеры                                        |
| 3         | Итоговое объяснение                                      | Только после завершения дела                                                           |
| Позже     | Короткие общие реплики Шефа о начале/конце расследования | После подготовки текста в i18n, не на каждое нажатие                                   |

Первые девять записей плана — короткая проба плюс восемь основных дорожек. Тексты извлекаются из case.json по content/narration/plan.json, а не сочиняются моделью. Из полной озвучки брифинга исключена фиксированная фраза «Шеф дал вам восемь раундов»: число раундов в игре выбирается, записывать неверное число нельзя. Числа, время, имена и ударения потребуется прослушать и при необходимости подготовить речевую редакцию без изменения смысла.

## Что пока не озвучиваем

Каждую кнопку, ошибки сети, численные показатели стоимости, вводимые имена игроков и динамические ответы ИИ. Личные улики/факты не зачитываются автоматически: это выдаст информацию другим участникам hot-seat. Для будущего проигрывателя обязательны явный запуск, пропуск/остановка, текстовая альтернатива и остановка при сворачивании/передаче. Файлы готовятся заранее и впоследствии работают офлайн; Cartesia-ключ не входит в APK.

## API и хранение

Ключ CARTESIA_API_KEY хранится в GitHub Repository Secret. Другие агенты запускают утверждённое задание; значение ключа читать/выводить не требуется. Для пробы отдельный workflow cartesia-sample.yml срабатывает только при явном добавлении метки cartesia-sample на PR ветки codex/cartesia-narration в этом же репозитории. Обычные unit/e2e и push платную генерацию не запускают.

Скрипт tools/generate-narration.py использует версию API 2026-08-14, модель sonic-3.6, WAV PCM 16-bit / 44,1 кГц / ru. Голос для пробы выбирается из доступных русских мужских библиотечных голосов; при заданной переменной CARTESIA_VOICE_ID используется она. Время/байты/хеш/параметры пишутся в отчёт, стоимость не выдумывается. Нет автоматических повторов после ошибок. Артефакт содержит только WAV и безопасный JSON, оригиналы остаются в игнорируемом work/cartesia.

Полная генерация — отдельный запуск --all --allow-paid с явно выбранным голосом после прослушивания пробы. В текущем шаге разрешена и запускается одна проба, не весь набор.

Источники API, проверены 2026-11-12: [TTS bytes](https://docs.cartesia.ai/api-reference/tts/bytes), [голоса](https://docs.cartesia.ai/api-reference/voices/list), [Sonic](https://docs.cartesia.ai/build-with-cartesia/tts-models/latest). Качество русского проверяется реальным прослушиванием, а не обещанием из документации.
