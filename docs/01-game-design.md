# 01. Геймдизайн: режим «Комната допросов»

## 1. Суть
Совершено преступление. У каждого игрока — свой детектив и свой блокнот. По очереди игроки обыскивают локации и допрашивают подозреваемых. Найденное по умолчанию **тайное**. Побеждает тот, кто первым правильно назовёт **виновного + мотив + способ** и подкрепит обвинение уликами.

- Игроков: 1–4 (1 — одиночный режим без экрана передачи).
- Длительность: 25–45 минут.
- Ориентация: только портретная.

## 2. Игровой цикл

```
Главное меню → Выбор дела → Настройка игроков → Брифинг (общий экран)
   → [Экран передачи → Ход игрока → Конец хода] × N раундов
   → Обвинение (в любой ход) → Финал: разоблачение и реконструкция
```

### 2.1. Настройка партии
- Количество игроков 1–4, имена, цвет (4 цвета-акцента: оранжевый, бирюзовый, бордовый, горчичный).
- Режим допроса:
  - **«Классика»** — вопросы из списка, работает офлайн, без ключа.
  - **«ИИ»** — свободные вопросы (текст/голос); доступен, только если сохранён рабочий ключ. Вопросы из списка тоже остаются.
- Лимит раундов: по умолчанию 8 (настройка 6/8/10).

### 2.2. Брифинг (общий)
Экран, который видят все: обложка дела, фото жертвы (портрет актёра с CSS-обработкой «фото из дела»), текст брифинга, карточки подозреваемых (портрет, имя, возраст, кто такой, связь с жертвой), список локаций. Кнопка «Начать расследование».

### 2.3. Экран передачи телефона
- Полностью закрывает предыдущее содержимое: «Передай телефон: **{Имя}**» в цвете игрока.
- Кнопка «Я — {Имя}» требует **удержания 1 секунду** (защита от случайного нажатия).
- В одиночном режиме не показывается.
- При сворачивании приложения посреди хода по возвращении тоже показывается этот экран (защита от подглядывания).

### 2.4. Ход игрока
Вверху: имя, номер раунда, кнопки «Блокнот», «Доска», «Обвинить».
Игрок выбирает **одно действие** за ход:

| Действие | Что происходит |
|---|---|
| **Обыск** | Выбрать локацию → коснуться одной зоны (хотспота). Открывается крупный план и описание; если там улика — она попадает в блокнот игрока. Можно осмотреть **до 2 зон** за ход. |
| **Допрос** | Выбрать подозреваемого → до **3 реплик** (вопрос из списка, свободный вопрос с ИИ или предъявление улики). |

После действия — кнопка «Завершить ход» → экран передачи следующему.

Зоны, которые игрок уже осмотрел, помечаются галочкой (у каждого игрока свои отметки). Одну и ту же улику могут независимо найти несколько игроков.

### 2.5. Допрос
Экран: сверху крупный портрет подозреваемого (эмоция меняется), полоска стресса, снизу чат.

Варианты реплики:
1. **Вопрос из списка** (`offlineQA` из дела). Некоторые вопросы появляются, только если у игрока есть определённая улика или факт (`requiresClueId` / `requiresFactId`). Ответ — заранее написанный текст. Каждый вопрос игрок может задать один раз.
2. **Свободный вопрос (ИИ)** — текст или голос. Перед отправкой — выбор тона: **Нейтрально / Давить / Сочувствовать**.
3. **Предъявить улику** — выбрать улику из своего блокнота.
   - Если улика есть в `breakpoints` этого подозреваемого и стресс ≥ `breakThreshold` (или у брейкпоинта `ignoreStress: true`) → **слом**: подозреваемый признаёт часть правды, игрок получает факты `revealsFactIds`. Портрет → `broken`.
   - Если улика в `breakpoints`, но стресс ниже порога → подозреваемый нервничает, стресс +2, подсказка: «Он явно занервничал. Надавите сильнее».
   - Если у подозреваемого есть `clueReactions` для этой улики — заранее написанная реакция (в ИИ-режиме ИИ получает её как смысл ответа).
   - Иначе — нейтральная реакция («Впервые вижу. При чём тут я?»).

**Стресс** (0–10, у каждого подозреваемого отдельно **для каждого игрока**):
- Тон «Давить» +2, «Сочувствовать» −1, «Нейтрально» 0; вопрос о теме, которую персонаж скрывает, +1; ИИ может добавить `stress_delta` в пределах −1…+2 (движок ограничивает).
- Стресс 10 → «Я требую адвоката»: этот подозреваемый закрыт для игрока на 1 его ход, затем стресс падает до 6.
- Стресс медленно спадает: −1 в начале каждого хода игрока (персонаж «успокаивается»).

Что открылось в допросе, записывается в блокнот игрока **каноническим текстом факта** из дела, а не пересказом ИИ.

### 2.6. Блокнот (личный)
Вкладки: **Улики** (карточки с картинкой, открываются на весь экран, у документов — отрисованный текст), **Факты** (что узнал на допросах и из улик), **Заметки** (свободный текст), **Хронология** (факты с указанным временем, отсортированы автоматически).
- Кнопка у улики/факта: «Выложить на общую доску» (+1 очко сотрудничества, видят все).

### 2.7. Общая доска
Пробковая доска: выложенные улики и факты всех игроков, фото подозреваемых. В v1.0 — просто просмотр с указанием, кто выложил. (Красные нити между карточками — после v1.0.)

### Дополнение к обыску: осмотр деталей (принято, ещё не реализовано; ADR-012)

Основа point-and-click уже есть: зоны комнаты → крупный план → улика. Принято добавить второй уровень взаимодействия для значимых предметов: нажать на статуэтку в кабинете, затем на скол её подставки в крупном плане, чтобы рассмотреть деталь и получить объяснение. Это **ещё не реализовано**.

Осмотр деталей уже открытого предмета не расходует дополнительные зоны хода; повторные нажатия не дают новых очков. Факт открывается после самостоятельного обнаружения детали. До находки нет прямых подсказок: подписей, выделения зон, стрелок или текста о сколе в описании предмета, блокноте и ИИ-репликах. Допустимы нейтральное обучение жестам, увеличение и удобная область попадания без видимого маркера. Кнопка автоматического раскрытия деталей не предусматривается. Действующая сборка пока работает по прежним правилам. Подробности, различие между находкой и обнаружением детали, совместимость сохранений — ADR-012.

### 2.8. Обвинение
Доступно в свой ход вместо действия или после него.
1. Выбрать виновного (портреты).
2. Выбрать мотив (список `motives` дела, 4–6 вариантов).
3. Выбрать способ (список `methods`, 3–5 вариантов).
4. Приложить **1–3 улики/факта** из своего блокнота как доказательства.

Проверка:
- Виновный, мотив и способ верны **и** среди доказательств есть хотя бы одна из `solution.keyEvidence` → **победа**, игра заканчивается.
- Если верны все три, но доказательств нет → «Прокурор не примет дело без улик»: обвинение не засчитано, но игрок **не выбывает** (один раз за игру).
- Иначе → игрок **выбывает**; дальше он может только смотреть доску (его ходы пропускаются).
- Все выбыли или кончились раунды → **финальное обвинение**: каждый оставшийся игрок по очереди делает обвинение без штрафа; побеждают все, кто прав. Если никто — «Дело не раскрыто».

### 2.9. Финал
- Экран «Как всё было»: 2–4 кадра-реконструкции (картинки из дела) + текст `solution.explanation` + правдивая хронология.
- Итоги: победитель, очки, у кого какие ключевые улики были найдены.

**Очки** (для таблицы итогов, не для победы): верное обвинение +10, каждая найденная ключевая улика +2, выложенная на доску улика/факт +1, сломанный подозреваемый +1.

### 2.10. Подсказки «Шефа»
Если к раунду `hint.afterRound` никто не нашёл нужную улику, в начале хода показывается подсказка Шефа (`hints` в деле). Работают офлайн.

## 4. Сохранение
- Партия сохраняется автоматически после каждого действия (состояние движка → JSON).
- «Продолжить» в главном меню возвращает к экрану передачи текущего игрока.
- Одна активная партия; новая — с подтверждением перезаписи.

## 5. Физические мини-игры (этап M6, после v1.0-ядра)
Привязаны к конкретным хотспотам через поле `minigame` в деле:
- `dust` — **встряхнуть телефон**, чтобы нанести порошок → проявляются отпечатки (акселерометр).
- `uv` — **закрыть датчик света ладонью** → «УФ-лампа» показывает следы (датчик освещённости; веб-заглушка — кнопка).
- `tilt` — **наклонить телефон**, чтобы заглянуть под мебель (гироскоп/акселерометр).
- `blow` — **подуть в микрофон**, чтобы сдуть пыль (уровень громкости).
У каждой мини-игры есть кнопка «Пропустить», чтобы игра оставалась доступной.

## 6. Тон и подача
- Сезон 1 — нуар: дождливый портовый город Ветрогорск, наши дни. Каждый сезон из 4 дел меняет мир, стиль картинок и труппу (ADR-031, `docs/seasons/`); тон и рейтинг 12+ общие. Сдержанная ирония, без жестокости в деталях (рейтинг 12+): тела не показываем, только контур/накрытая простынёй фигура, следы — без натурализма.
- Тексты коротко: реплики подозреваемых 1–3 предложения.
- Звук (необязательно в v1.0): дождь, джаз-эмбиент, стук печатной машинки на появление факта, вибрация при «сломе».

## Уточнение UI ИИ-допроса (ADR-014, запланировано)

В ИИ-режиме свободный вопрос и отправка идут первыми среди блоков вопросов; готовые офлайн-вопросы расположены ниже в раскрывающемся списке, свёрнутом по умолчанию. В классическом режиме офлайн-вопросы остаются основным открытым управлением. Лимиты и факты эта перестановка не меняет.

## Лимиты после телефонной проверки M2 (ADR-013)

Партия поддерживает 1–5 игроков. В ИИ-режиме три успешные реплики одному подозреваемому за ход: вопросы ИИ, офлайн-вопросы и предъявления используют общий бюджет. В классике три. Ошибки/отмена бюджет не расходуют; стресс и адвокат могут ограничить разговор раньше. Новые правила заменяют ранние числа для ИИ-режима выше.

## Реализованный первый осмотр детали (ADR-019)

Статуэтка: после находки видны предмет и нейтральное описание. Факт о свежем сколе открывается только после нажатия на соответствующую область крупного плана. Можно увеличивать и прокручивать изображение; нет подписи искомой детали, подсветки или стрелки. Осмотр уже найденного предмета не расходует дополнительную зону/реплику и не даёт повторных очков. Каждый игрок исследует самостоятельно. Из блокнота предмет открывается без чужого closeup и возвращает в блокнот. Остальные кандидаты — POINT-AND-CLICK-REVIEW.md.
