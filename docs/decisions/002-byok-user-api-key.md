# ADR-002: Ключ пользователя (BYOK) на старте, подписка — позже

**Дата:** 2026-11-11 · **Статус:** принято

## Контекст
ИИ-допросы стоят денег (≈0,5–3 ₽ за партию). На старте неизвестен спрос; платёжная инфраструктура (Google Play Billing не работает для РФ, нужна RuStore Billing) — заметный объём работы.

## Решение
- v1.0: игрок вставляет свой ключ aitunnel.ru. Ключ хранится только на устройстве (Android Keystore), запросы идут напрямую с телефона в aitunnel. Наши серверы ключ не видят.
- Без ключа игра полностью проходима (режим «Классика»).
- При достаточном числе скачиваний — подписка (M7): наш ключ на сервере №2 за ИИ-прокси, оплата через RuStore Billing и Google Play (RevenueCat).

## Последствия
- `AiClient` — интерфейс; позже добавится `ProxyAiClient`.
- Нужна понятная инструкция «Где взять ключ» и прозрачность стоимости (заголовки `cost-rub`, `balance`).
- Политика конфиденциальности должна описать, что ключ и тексты вопросов уходят в aitunnel.
