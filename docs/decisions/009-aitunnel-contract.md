# ADR-009: Контракт aitunnel и предварительные модели M2

**Дата:** 2026-11-11 · **Статус:** принято, реальные запросы не проверены

## Контекст

В плане API-id моделей совпадали с URL-slug страниц. Публичная документация уточняет API-id и даёт проверку баланса без генерации. Настоящего ключа в этой сессии нет, бенчмарк не запускается.

## Источники

Прочитаны 2026-11-11: https://aitunnel.ru/docs/api-reference, https://aitunnel.ru/docs/reasoning, https://aitunnel.ru/docs/structured-outputs, https://aitunnel.ru/docs/api/balance и страницы моделей qwen3-7-flash, deepseek-v4-flash, gemini-2-5-flash-lite. GET /v1/models без ключа вернул 401; платные POST не выполнялись.

## Рассмотренные варианты

1. Сохранить URL-slug в запросах — расходится с опубликованным API-id.
2. Заменить основную модель по предположению о качестве — нет бенчмарка, необоснованно.
3. Исправить API-id и оставить выбор предварительным до ручного бенчмарка — выбран этот вариант.

## Решение

- Основная предварительно qwen3.7-flash, запасная deepseek-v4-flash, третий кандидат gemini-2.5-flash-lite. Это исправление идентификаторов, не утверждение победителя бенчмарка.
- Публичные страницы DeepSeek/Gemini заявляют JSON Schema: для них response_format=json_schema с полной схемой и strict=true. Для Qwen подтверждения JSON Schema на странице нет — json_object по исходному плану; работа JSON-режима требует проверки ключом.
- reasoning={enabled:false, effort:"none"}, max_tokens=400, temperature=0.8, stream=false. Значение exclude не используется как замена отключения: оно скрывает текст, но не исключает оплату мыслей. Фактическая поддержка отключения выбранной моделью не подтверждена без smoke.
- Проверка ключа — GET /v1/aitunnel/balance (документирован как получение баланса), без chat/completions и генерации. Ключ хранится только после успешного ответа.
- В допросе: таймаут 20 с, максимум две попытки основной модели, третья — запасная только при включённой пользователем настройке. Невалидный JSON/guard также может привести к повтору. Авторизация, недостаток средств, лимит, несовместимость параметров и отмена не вызывают автоматических повторов; пользователь выбирает другую модель/устраняет причину.
- После отмены/смены хода устаревший ответ не применяется. Отклонённый ответ не расходует игровую реплику, но провайдер мог списать деньги: стоимость завершённых попыток учитывается, неизвестная стоимость помечается явно.
- Читаются cost-rub/balance и актуальные usage.cost_rub/usage.cost/usage.balance (рубли по документации). Неизвестная сумма не отображается как достоверный ноль.
- Реальный smoke запускается только вручную с AITUNNEL_API_KEY и --allow-paid: 20 сценариев на модель, 60 запросов для трёх кандидатов без скрытых повторов. Отчёт маскирован и сохраняется в игнорируемый work/ai-benchmark. Живость оценивает владелец, не агент автоматически.

## Последствия

До бенчмарка нельзя обещать качество, цену, задержку и поддержку всех параметров. Доступен весь код и тесты на MockAiClient; окончательный выбор модели остаётся вопросом владельцу в STATUS. Документы 02/04 обновлены, чтобы URL-slug больше не выдавался за API-id.
