# ADR-011: Генерация арта агентом по просьбе владельца

**Дата:** 2026-11-12 · **Статус:** принято

## Контекст

Арт-библия и M3 предполагают, что картинки генерирует владелец. Пока проверяется M2, владелец прямо попросил агента сгенерировать картинки.

## Варианты

Генерация владельцем либо встроенным image_gen агентом по тем же промптам.

## Решение

Использовать image_gen и STYLE_CORE из арт-библии. Первый набор — четыре самостоятельные вертикальные иллюстрации: обложка и три локации. Результаты выдаются в чат. Подключение WebP, подбор координат зон и эмоций остаются отдельной работой M3; этап не объявляется закрытым. Ключ aitunnel и игровые ИИ-клиенты не используются.

## Последствия

Источник генерации изменился с согласия владельца; требования стиля, отсутствия текста, размеров и визуальной приёмки сохраняются. Ветка подготовки codex/pilot-art отделена от проверяемой M2.
