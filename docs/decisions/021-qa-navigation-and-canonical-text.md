# ADR-021: Безопасная навигация, debug-инструменты и канонические признания

**Дата:** 2026-11-12 · **Статус:** принято.

## Контекст

QA обнаружил возврат к настройке партии через историю, неудобный допрос и искусственные точки с запятой. Канон содержит признания Веры и Ольги по четыре предложения (включая прямую речь), старый валидатор требовал максимум три.

## Варианты

Сократить канон, оставить сломанную пунктуацию либо уточнить лимит признаний. Для истории — накапливать маршруты или заменять текущий маршрут с явной обработкой системной кнопки.

## Решение

- Восстановить ровно 31 текст: предложения разделены точками; `?..` — каноническое вопросительное многоточие, одиночное `?.` запрещено. Признания — до четырёх предложений, обычные offlineQA — до трёх; требования ИИ не меняются.
- Переходы `replace` и одна восстанавливаемая защитная запись истории браузера, защита S03–S05 при активной партии, явное подтверждение перезаписи и флаг в START_GAME. Android backButton через платформенную обёртку; браузерная история использует ту же политику.
- Редактор S17 доступен только в dev/debug/e2e web-сборках; production не содержит его модуля. Для Android Studio подготовить web-ресурсы режимом debug перед cap sync.
- Заметки и действия сохраняются последовательно. Смена способа ввода допроса не создаёт новую партию и не сбрасывает квоту.

## Последствия

Схема JSON не меняется. S17 копирует координаты, а не редактирует файлы на устройстве. Новые снимки e2e игнорируются; только выбранные копируются в отчёт. APK по указанию владельца не собирается — ни локально, ни в CI этого PR. Физическая проверка Android остаётся в MT-017.
