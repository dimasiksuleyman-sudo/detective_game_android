# ADR-025: Кодовый сейф и осмотр содержимого

**Дата:** 2026-11-12 · **Статус:** принято, четыре пункта утверждены владельцем.

## Контекст и варианты

Прежний сейф открывался наличием числового факта, выдавая бухгалтерию автоматически. Теперь игрок сам соединяет намёк в ежедневнике и дату на фотографии. Возможны жёсткая проверка наличия фактов или проверка введённого кода: выбрана последняя, как явно утвердил владелец для party-игры.

## Решение

- Схема дела v3: у хотспота `lock` (combination, digits, code, deductionFactIds) и `container` (image, items с clueId/rect). Валидатор моделирует самостоятельную дедукцию через AND обоих фактов; движок не требует этих фактов, проверяя сам код. Это разные задачи, не противоречащие друг другу.
- Неверные попытки бесплатны. Верное первое открытие тратит одну зону обыска этой комнаты; повторный просмотр бесплатен. Личное openedLocks хранится у игрока. Предметы внутри собираются отдельно без новых действий/очков осмотра; за ключевую улику сохраняются прежние очки движка.
- Четыре предмета содержат существующую бухгалтерию и три новые улики/факта. Ложные следы Веры и Ольги объясняются уже существующими долгом/гостиницей. Визитка подтверждает запись о юристе. Правила обвинения не меняются.
- Бухгалтерия без имени автора; имя — естественная надпись поверх рисунка разворота (кодом, согласно арт-библии). Факт автора только в детали осмотра. Брейкпоинт Глеба требует этот факт. Ни подсветки, ни инструкции «найти подпись» до обнаружения.
- Сохранение envelope v3 читает v1/v2/v3. Старый f-safe-code заменяется на f-safe-hint; старое открытие/владение бухгалтерией сохраняет открытый сейф. Старая бухгалтерия уже называла автора: при переносе v1/v2 известная подпись сохраняется вместе с найденной деталью, независимо от слома. Уже раскрытая денежная тайна Глеба сохраняется. В новых v3-партиях подпись ищут сами; загрузка её не выдаёт. Улики/факты/заметки/очки не стираются. Публичная доска мигрирует тот же id.
- Формат inspection расширен текстовыми overlays: это наблюдаемые записи на бумаге, а не автоматические факты; в контекст ИИ они не передаются.

- По замечанию владельца надписи ограничены полями бумаги; размер рассчитывается по ширине разворота и длине строк, масштабируется вместе с ним. Основные кнопки приложения занимают ширину контейнера с текстом по центру, меню разделено на вертикальные строки. Координатные области осмотра и колёсики сохраняют геометрию рисунка/механизма.

## Последствия

Пилот v4, minAppVersion 0.3.3; приложение 0.3.3/code7 для локальной Android Studio. Старые приложения новые сохранения не читают. Кратчайший путь с известным кодом может быть короче самостоятельной дедукции — допустимо по утверждённой party-механике; проверяются оба пути. Неверный код, личная изоляция, подпись/слом и миграция проверяются тестами. APK не собирается по прямому указанию владельца (полный запрет облачной/локальной сборки агентом — ADR-024; ADR-022 относится к afterBreak).
