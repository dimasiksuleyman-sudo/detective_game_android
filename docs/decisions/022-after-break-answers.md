# ADR-022: Правдивые ответы после раскрытия темы тайны

**Дата:** 2026-11-12 · **Статус:** принято.

## Контекст

Готовые вопросы продолжали возвращать прежнюю ложь после признания по той же теме. Общий признак «сломлен» недостаточен: у Глеба две независимые тайны.

## Варианты

Скрывать вопрос, заменять все ответы сразу после слома или явно связать замену с раскрытой темой.

## Решение

Необязательное `offlineQA.afterBreak: { truthId, answer }`. Движок выбирает правдивый ответ только при наличии этого truthId у текущего игрока. Условия доступности, уже заданные вопросы и лимит реплик сохраняются; факты по-прежнему открывает движок. История прежней лжи не переписывается. Валидатор проверяет локальную принадлежность truthId и длину ответа.

Это обратимое добавление к схеме v2, без изменения сохранений. Пилот version 3 требует minAppVersion 0.3.2: старый клиент не должен молча игнорировать семантику afterBreak. Поля добавлены ко всем противоречащим признанию вопросам четырёх подозреваемых.

## Последствия

У разных игроков и разных тайн ответы могут различаться. Слом по одной теме не раскрывает другую. ИИ не выбирает момент раскрытия; promptBuilder уже передаёт только признанную правду.

Документы показывают исходные записи и реквизиты, а не факты-выводы. Для пяти бухгалтерских строк канон задаёт получателя и подпись, но не суммы/даты: выбраны оформительские значения, они не добавляют игровых фактов, алиби или условий решения. Валидатор запрещает полное совпадение любого поля/строки документа с любым фактом после нормализации регистра и пробелов.
