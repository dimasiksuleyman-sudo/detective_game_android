# ADR-017: Пробная озвучка через Cartesia и секрет репозитория

**Дата:** 2026-11-12 · **Статус:** принято для одной пробы, полный набор/проигрыватель ещё не подключены

## Контекст

Владелец попросил выбрать фразы, извлечь их из дела и сгенерировать озвучку. Кнопки настройки облачного окружения у него нет; по инструкции создал Repository Secret CARTESIA_API_KEY и подтвердил готовность. Такой секрет доступен заданиям разных агентов без раскрытия значения в чате.

## Варианты

TTS на телефоне во время игры либо предварительная генерация статичных файлов. Выбран второй путь: офлайн, без ключа в APK и без оплаты при каждом прослушивании.

## Решение

Отдельный ручной путь генерации, не unit/e2e. Манифест извлекает брифинг/существующие подсказки/финальные подписи/объяснение из дела. Одна короткая проба через GitHub Actions по явной метке cartesia-sample в PR ветки codex/cartesia-narration того же репозитория. Разрешён один POST, без повторов; GET списка голосов подбирает русский мужской библиотечный голос. Ключ только в env шага, никогда в коде/параметрах команды/артефактах. urllib сохраняет стандартную проверку TLS и настройки прокси. Перенаправления запрещены. Ответ ограничен размером, WAV проверяется до записи. Полный набор после оценки голоса требует отдельного запуска.

## Последствия

ADR-015 уточняется: Cartesia теперь выбран для пробы, а не только идея. Голос/произношение/стоимость ещё оцениваются. Аудио пока не попадает в приложение. При подключении нельзя автоматически раскрывать личные факты или финальные спойлеры; обязательна остановка при передаче/сворачивании. Формат дела пока не меняется. Секреты GitHub могут быть недоступны агенту даже в списке метаданных — это не мешает workflow читать привязанный секрет.

## Утверждение голоса и полного набора

После прослушивания владелец сообщил «отлично подходит, го дальше». Sergei утверждён; разрешены восемь основных дорожек из плана. Отдельная метка cartesia-full запускает восемь POST без повторов, жёстко с утверждённым voice id. Исходные WAV сохраняются артефактом; отдельный шаг без Cartesia-ключа конвертирует MP3 64 kbps mono и коммитит только аудиоресурсы/манифест в рабочую ветку. Приложение не получает ключ и не вызывает TTS. Шаг записи получает минимальное contents:write, остальные ручные задания остаются read-only.
