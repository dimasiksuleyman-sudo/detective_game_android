# ADR-015: Сообщения ошибок и возможная озвучка вступления

**Дата:** 2026-11-12 · **Статус:** тосты запланированы; Cartesia.ai — кандидат, не выбранный провайдер

## Контекст

Владелец прислал экран сетевой ошибки: сообщение отображается постоянно и занимает значительную часть экрана, фраза «реплика не списана» повторяется. Просит в дальнейшем показывать такие ошибки тостом, но разрешает оставить текущий блок на время разработки. Также предложил озвучку начальной истории через cartesia.ai.

## Варианты

Оставить постоянный блок либо использовать краткий тост для временных ошибок. Для вступления: только текст либо необязательная заранее подготовленная аудиодорожка.

## Решение

Запланировать краткие тосты для временных ошибок сети/ИИ в полировке M4. На время разработки оставить текущий вид по прямому разрешению владельца. Убрать дублирование формулировок в будущем пакете исправлений. При реализации обеспечить читаемость сообщения, доступность для экранного диктора и отсутствие перекрытия управления. Существенные действия, требующие исправления ключа/баланса, не должны теряться вместе с исчезнувшим тостом: подробности доступны в соответствующих настройках. Учёт стоимости остаётся отдельно, а не исчезает вместе с ошибкой.

Внести Cartesia.ai как кандидата для предварительной генерации озвучки вступительной истории/брифинга. Пока не подключать API, не создавать аккаунт, не делать платных вызовов. Предлагаемый путь: подготовить дорожку заранее, включить в ресурсы дела, воспроизводить офлайн с пропуском/остановкой и текстовой альтернативой. Голосовое распознавание M4 — отдельная функция. Голос, условия использования, стоимость и способ подготовки требуют выбора перед реализацией; никаких утверждений о проверенных возможностях сервиса пока нет.

## Последствия

Для тостов нужны UI-проверки и телефонная приёмка. Для аудио понадобится отдельное решение о формате ресурсов/паков и платформенной обёртке воспроизведения; текущая схема дела не меняется. Эти идеи не реализованы, текущую проверку M2 не останавливают.
