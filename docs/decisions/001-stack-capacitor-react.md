# ADR-001: Стек — Capacitor + React + TypeScript

**Дата:** 2026-11-11 · **Статус:** принято

## Контекст
Игра — в основном интерфейс: чат допроса, карточки, блокнот, доска, портреты с плавной сменой эмоций. Движок с физикой и сценами не нужен. Код пишет ИИ-агент. Нужен офлайн и задел на iOS/веб.

## Рассмотренные варианты
1. **Capacitor + React + TS** — HTML/CSS идеальны для такого UI; агент лучше всего пишет на React/TS; почти всё тестируется в браузере (Playwright); задел на iOS/PWA. Минусы: WebView на слабых устройствах (решается: анимировать только transform/opacity, WebP), для датчика света и RuStore Billing нужны свои нативные плагины.
2. Kotlin + Jetpack Compose — нативная производительность; минусы: только Android, тестирование UI тяжелее без эмулятора, агент пишет медленнее.
3. Flutter — хорош, но Dart реже, веб-тестирование слабее.
4. Godot/Unity — избыточно для интерфейсной игры.

## Решение
Capacitor + React + TypeScript + Vite. Владелец согласовал.

## Последствия
- Все нативные функции — через `src/platform/` с веб-заглушками.
- Свой Kotlin-плагин датчика света (M6) и RuStore Billing (M7).
- Производительность проверяет владелец на бюджетном телефоне (M4).
