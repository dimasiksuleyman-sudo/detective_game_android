# ADR-020: Весь арт генерирует агент, по полному списку ассетов

**Дата:** 2026-11-12 · **Статус:** принято · **Заменяет:** ADR-011 (как разовое исключение)

## Контекст

По исходному плану картинки генерировал владелец. ADR-011 разрешил агенту сгенерировать первый набор (обложка и три локации), затем добавилась статуэтка. Задачи «весь арт» не было, полного списка ассетов со статусами тоже: на 2026-11-12 в игре 52 заглушки (36 портретов, 9 крупных планов, 4 улики, 3 кадра реконструкции), и это не было видно как недоделка этапа.

## Решение

- Агент генерирует весь арт сам (встроенная генерация изображений), по промптам `docs/05-art-bible.md`.
- `art/ASSETS.md` — полный список всех картинок со статусами; этап/дело не закрыты, пока есть заглушки.
- Пачки по типу, контакт-лист после каждой пачки, без ожидания одобрения; отклонённое переделывается.
- Портреты — мастер + правки по референсу; при невозможности — сразу сообщить владельцу.

## Последствия

- Правила — в `AGENTS.md` §4–6. `05-art-bible.md` больше не называет владельца источником генерации.
- Владелец одобряет арт по контакт-листам; физическая проверка на телефоне — MT-011.
