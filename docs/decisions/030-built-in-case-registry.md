# ADR-030: Реестр встроенных дел и сохранение caseId

**Дата:** 2026-11-12 · **Статус:** принято по заданию владельца (шаг 0 CASE-RUNBOOK).

## Контекст

UI, ИИ и озвучка использовали пилот напрямую. В GameState уже был caseId, но чтение сохранения отвергало любое другое дело. Перед утверждённым вторым делом нужен общий механизм без добавления производственного контента.

## Варианты

1. Ручной список импортов — каждое новое дело требует правки приложения.
2. Загрузка JSON по сети при выборе — лишняя асинхронность для встроенного офлайн-контента.
3. Реестр из public/cases/*/case.json при сборке — выбран этот вариант.

## Решение

- Vite включает JSON встроенных дел в bundle. createCaseRegistry проверяет Zod-схему, соответствие id имени каталога и уникальность. listCases возвращает список для S03, loadCase(caseId) — точное дело. Неизвестный id отвергается; подмены пилотом нет. Добавление каталога с case.json включает новое встроенное дело при следующей сборке.
- Выбор для новой партии хранится отдельно от существующей партии до START_GAME. Стор передаёт движку выбранное дело; остальные действия, UI и ИИ получают дело по GameState.caseId. Просмотр и отмена настройки не переписывают текущую партию.
- Сохранение envelope v4 в прежнем IndexedDB-ключе требует caseId. Читаются v1/v2/v3/v4. В v1–v3 отсутствующий caseId означает case-001-blue-owl. Прежние миграции сейфа/подписи/доски сохраняются только для пилота. Неизвестная версия или дело дают ошибку без перезаписи исходного. Заметки, история, очки и признания сохраняются.
- Озвучка: public/cases/<id>/audio/manifest.json; поиск по caseId, id и точному экранному тексту. Отсутствующая/устаревшая дорожка скрывается. Манифест не может ссылаться на чужое дело. Музыкальные треки остаются общими, текущий набор пилота используется без изменений.
- Манифесты готовности арта читаются из art/*/manifest.json; относительные картинки сверяются в пределах дела, труппа общая.
- Case schema остаётся v3: lock уже поддерживает 1–8 цифр. SafePuzzle сбрасывает колёсики при смене дела/замка/длины, длинный ряд прокручивается. Пилот сохраняет четыре цифры и код 1408.
- Фикстура tests/fixtures/cases/case-e2e-mini включается только при MODE=e2e. Она использует существующие данные/изображения пилота, другой caseId/брифинг и код 214 на трёх колёсиках. Production-проверка отвергает её маркеры в dist. В public остаётся только пилот.

## Последствия

Приложение 0.3.5 / code 9. После записи v4 откат к прежнему приложению не поддерживается. Скачиваемые паки и сервер остаются M5. Генерация озвучки и переделка старого Cartesia-workflow в этот кодовый PR не входят; платные вызовы не выполнялись. Дело № 2 начинается отдельной веткой от свежего main только после слияния этого PR.
