# ADR-019: Осмотр деталей, схема дела v2 и совместимость

**Дата:** 2026-11-12 · **Статус:** принято, реализация начата

## Контекст

Обход экранов подтвердил раннее раскрытие скола и ошибки повторного просмотра из блокнота. ADR-012 требует самостоятельного обнаружения. Это меняет момент получения факта, формат дела и сохранение, поэтому одной правки UI недостаточно.

## Варианты

Оставить факт при находке либо выделить исследование в отдельное действие. Выбран отдельный детерминированный осмотр без расхода дополнительных зон.

## Решение

Схема дела v2 добавляет необязательный clue.inspection: image и details (id, rect нормализованный 0..1, text после обнаружения, revealsFactIds, concealedTerms для пост-фильтра). Схема v1 без inspection продолжает читаться; не допускаем inspection при schemaVersion=1, чтобы старые приложения не молча теряли механику. Пилот v2, version 2, minAppVersion 0.3.0; приложение 0.3.0/code4. В v2 метаданные игроков согласованы с поддержкой пяти игроков.

INSPECT_CLUE с координатами проверяет владение уликой, текущего активного игрока, фазу и область попадания. Деталь отмечается в Player.inspectedDetails, выдаёт только свои факты, не меняет бюджет обыска/разговора/очки. Повтор идемпотентен. В финальном обвинении можно перечитать найденное, но не вести новый поиск. Для пилота из немедленных revealsFactIds статуэтки удаляется f-statuette-weapon; он переносится в деталь скола. Начальные описания нейтральны, реакции предъявления не раскрывают скол.

Сохранение пишет envelope version2 в прежний storage key, читает v1/v2. При миграции старые уже известные факты остаются; если такой факт был открыт раньше, соответствующая деталь помечается изученной при владении предметом. Новые пустые поля получают значения по умолчанию. Старое приложение не должно открывать новый envelope; понижение версии после новых сохранений не поддерживается.

Валидатор проверяет ссылки/координаты/уникальность и отдельную достижимость фактов осмотра. Он запрещает ранние источники gated-фактов и раскрывающие термины в стартовых описаниях/реакциях. Движок и promptBuilder отсекают gated fact id до открытия, пост-guard отклоняет раскрывающие слова, не передавая список скрытых терминов самой модели. Это эвристика текста, а не формальная гарантия против всех перефразировок.

UI: один рисунок, увеличение/прокрутка, невидимые точки без прямых подсказок. Из блокнота возвращаемся в блокнот и очищаем чужой closeup. Публичная доска пока не получает возможность раздавать личные открытия.

## Последствия

Нужны обновлённые пилот, валидатор, тесты миграции/идемпотентности/разделения игроков/антиспойлера и физический MT-012. Из-за новой версии приложения/миграции выполняется одна контрольная APK-сборка по ADR-007, без повторения на документационных правках. Остальные места point-and-click перечислены в POINT-AND-CLICK-REVIEW; они не объявляются реализованными.
