# ADR-032: Направление — PWA и несколько языков

**Дата:** 2026-11-13 · **Статус:** принято владельцем как направление; реализация — после релиза русской версии в сторах.

## Контекст

Capacitor выбран в том числе ради веб-версии. Владелец хочет, кроме RuStore/Google Play, развивать мультиязычное PWA (браузер, установка «на главный экран», iPhone без App Store). Сейчас игра только на русском. Чтобы потом не переписывать, новые изменения уже сейчас не должны добавлять привязку к русскому языку.

## Рассмотренные варианты

1. Только сторы, только русский — проще, но закрывает iOS и зарубежную аудиторию.
2. Сразу всё: PWA и языки до релиза — отодвигает релиз и сезон 1.
3. **Поэтапно:** сначала релиз RU в сторах, затем RU-PWA, затем инфраструктура языков и английский на одном деле, затем остальные языки — **выбрано**.

## Решение

### Порядок

1. Сезон 1 и релиз RU в сторах — без изменений.
2. **PWA (RU):** манифест и service worker (оболочка приложения кешируется, дела — по кнопке «Скачать для офлайна»), `navigator.storage.persist()` для сохранений, уведомление «Доступна новая версия», хостинг на сервере № 1 с HTTPS и выкладкой из `main`. Ключ ИИ в браузере хранится без аппаратной защиты — честное предупреждение в настройках. Первым шагом проверить CORS aitunnel с веб-домена.
3. **Языки:** словари интерфейса `src/i18n/<lang>.ts` и выбор языка; перевод дела — отдельный файл с теми же id (`case.<lang>.json` или аналог, формат — отдельным ADR при реализации), валидатор проверяет полноту перевода; озвучка на каждом языке (новые дорожки, одна попытка на файл); промпты ИИ и защита от утечек — на каждый язык со своими тестами. Первый язык — английский на одном деле.
4. **ИИ для зарубежных игроков:** aitunnel — российский сервис с оплатой в рублях. Нужен второй провайдер (OpenAI-совместимый, например OpenRouter) с выбором в настройках.

### Правило с сегодняшнего дня (записано в AGENTS.md §3)

Новый код не добавляет русскоязычную логику вне `src/i18n/` и данных дела. Если без языковых правил не обойтись, они собираются в одном месте и помечаются как правила языка `ru`, чтобы потом добавить такие же для другого языка.

### Где русский язык зашит сейчас (перенести при реализации п. 3)

- `src/ai/promptBuilder.ts` — тексты системного промпта и инструкций модели.
- `src/ai/guard.ts` — запасная реплика «Я уже всё сказал…», нормализация «ё».
- `src/content/inspectionKnowledge.ts` — поиск скрытых терминов по русским словоформам.
- `src/content/validate.ts` — правила пунктуации и регулярка «убил/убийца/виновен».
- Правило «в произносимом тексте нет цифр» (CASE-RUNBOOK) — про русскую нормализацию ElevenLabs; для других языков проверить отдельно.
- Контент: `public/cases/*/case.json`, `content/narration/*.json`, строка меню в `src/i18n/ru.ts`.

### Проверка качества перевода

Владелец (английский ~B2) проверяет понятность и логику дела. Естественность и стиль — самопроверка модели (обратный перевод, вычитка отдельным запросом) и хотя бы один носитель-тестер на язык перед выпуском.

## Последствия

- Картинки переиспользуются на всех языках (в них нет текста — правило арт-библии); документы рисуются кодом и переводятся как текст.
- Стоимость каждого языка растёт с числом дел: перевод, вычитка, озвучка.
- PWA даёт iOS и упрощает будущую оплату подписки (M7) без комиссии стора.
