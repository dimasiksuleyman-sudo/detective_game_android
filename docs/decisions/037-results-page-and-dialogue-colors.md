# ADR-037: Отдельная страница «Итоги» и цвет реплик в диалогах

**Дата:** 2026-11-13 · **Статус:** принято (просьба владельца)

## Контекст

Владелец: на финале «каша-малаша» — сверху длинное объяснение, итоги внизу, их никто не видит. В допросе вопрос игрока и ответ подозреваемого сливаются. Различать говорящих нужно во всём приложении и во всех делах — нынешних и будущих.

## Рассмотренные варианты

1. Переставить блоки на одном экране (итоги сверху) — минус: экран всё равно длинный, кнопки внизу.
2. **Две страницы финала + единый компонент реплики** — плюс: коротко и понятно, правило действует для любого дела без правок данных.
3. Цвет говорящего задавать в данных дела — минус: лишняя работа на каждое дело, легко забыть.

## Решение

Вариант 2.

- **«Итоги»** открываются первыми: победители, очки «N из M возможных», формула, рекорд. Кнопки: «Как всё было», «Сыграть ещё», «В меню». Разгадка — отдельной страницей, с кнопкой «К итогам». Нераскрытое дело: «Дело не раскрыто», «Да, показать разгадку», «Нет, сыграть ещё раз», «В меню». Общая нижняя кнопка «В меню» на финале не дублируется.
- **Реплики:** компонент `src/components/Exchange.tsx` и стили `.say*` в `src/theme/global.css`. Игрок — справа, сине-серый, подпись «Вы». Персонаж — слева, светлый, подпись с именем. Шеф — тёмная плашка с оранжевой полосой, подпись «Шеф».

## Последствия

- Новый экран не нужен: состояние `finaleView` внутри S14; сохранения не меняются.
- e2e проверяют «Итоги» и переход к разгадке.
- Любой будущий диалог (ИИ, новые персонажи, свидетели) рисуется через `Exchange`.
