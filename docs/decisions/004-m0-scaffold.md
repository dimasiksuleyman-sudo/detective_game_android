# ADR-004: Воспроизводимый каркас M0 и границы этапа

**Дата:** 2026-11-11 · **Статус:** принято

## Контекст

В исходной ветке есть только документация. M0 требует браузерного приложения, Android и тестов. Окончательный appId неизвестен. Пользователь просит останавливаться после каждого этапа; установка APK доступна только владельцу.

## Рассмотренные варианты

1. HashRouter — адрес сохраняется при перезагрузке и не требует серверных правил; MemoryRouter — проще, но не сохраняет текущий экран при перезагрузке.
2. Системные шрифты — зависят от устройства; локальные PT Mono/PT Sans — кириллица, открытая OFL, одинаковое отображение без сети.
3. Реализовать будущие подсистемы сразу — нарушает этапность; создать явно пустые модули с назначением и этапом — сохраняет границы M0.

## Решение

- HashRouter, CSS Modules, локальные PT Mono/PT Sans из Fontsource; лицензии в `public/licenses/` и `docs/licenses.md`.
- Актуальные стабильные пакеты на дату установки; точные версии без диапазонов в package.json и npm lockfile. Node 24 LTS для локальной среды и CI, JDK 21 для Android.
- Временный appId `com.example.interrogation`, название «Комната допросов», версия каркаса 0.0.1. Вопрос appId остаётся владельцу.
- S01–S16 — отдельные лениво загружаемые экраны с явным обозначением заглушки. Навигационный каталог доступен для smoke-проверки, игрового состояния нет.
- Пустые модули будущих этапов не имитируют готовые native/API-функции. ИИ-вызовов и ключей в M0 нет; на M2 автоматические тесты будут использовать только MockAiClient.
- M0 получает отдельную рабочую ветку `codex/m0-project-scaffold` от ветки плана. После отчёта работа останавливается; M1 начинается отдельным продолжением. Автоматические результаты и ручная приёмка фиксируются раздельно; до MT-001 M0 нельзя считать полностью закрытым.

## Последствия

- Шрифты работают без внешних запросов; лицензии входят в сборку.
- Для реальной игры M1 заменит заглушки; M2–M6 подключат свои библиотеки по мере необходимости.
- Владелец должен утвердить appId до публикации и проверить установку APK. Эта запись не меняет критерии готовности roadmap.
