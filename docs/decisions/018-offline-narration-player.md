# ADR-018: Офлайн-проигрывание утверждённой озвучки

**Дата:** 2026-11-12 · **Статус:** принято

## Контекст

Голос Sergei утверждён владельцем, разрешён полный набор. Нельзя раскрывать личные факты вслух и проигрывать финальные спойлеры до завершения дела.

## Варианты

Автозапуск при смене экрана либо явные элементы воспроизведения. Выбран явный запуск.

## Решение

Встроенные MP3 и отдельный audio/manifest.json с исходным текстом, длительностью и хешем. Без изменения схемы case.json/сохранения. Веб/Android WebView воспроизводят через src/platform/audio.ts и компонент с нативными HTML controls; новых Capacitor-плагинов нет. Только одна дорожка одновременно. Уход с экрана, сворачивание и передача телефона останавливают звук и сбрасывают позицию. Нет autoplay, предварительная загрузка none. Игровые действия не блокируются ошибкой аудио, текст всегда доступен.

Проигрыватель показывается только при точном совпадении текста манифеста с отображаемым текстом. Для брифинга убрана фиксированная фраза про восемь раундов; выбранный лимит показывается отдельно. Подсказки звучат только из уже показанного g.hint. Финальные аудио только при phase=finished на экране финала. Личные улики/ответы ИИ автоматически не озвучиваются. Один голос используется и для исходных подсказок Шефа в первом наборе, новых подсказок нет.

## Последствия

Нужна проверка воспроизведения/остановки и отсутствия преждевременных финальных controls в браузере; производительность, звук, фон/гарнитура на телефоне остаются MT-013. MP3 уменьшают размер по сравнению с WAV, исходники хранятся отдельно. Формат будущих скачиваемых аудиопаков уточняется в M5; это sidecar только встроенного дела.
