# ADR-029: Иконка и управляемый сплэш

Принято по заданию владельца. Основной мотив — лупа с оранжевой лампой (#D2691E), фон иконки #1E2A33, сплэш #12181D. Исходники art/app и art/store — LFS, подготовленные размеры Android — обычный git. @capacitor/assets закрепляется точной версией; все плотности воспроизводятся из assets/. Monochrome добавляется XML, если генератор не поддерживает его. Нативный SplashScreen.hide вызывается через обёртку после загрузки сохранения и готовности первого экрана, в том числе при ошибке чтения. Искусственной задержки нет. Android 12+ использует системную иконку и фон, Android 8–11 — центральный мотив на квадратном изображении. Физические проверки — очередь MT; APK собирает владелец (ADR-024).

Дополнение по QA владельца: кнопки обыска остаются на своих местах. Причина непрокручиваемой картинки — touch-action: pinch-zoom. Заменено на pan-y pinch-zoom; вертикальный жест не должен превращаться в поиск улики. Отступы учитывают максимум env(safe-area-inset-_) и CSS-переменных --safe-area-inset-_, которые передаёт SystemBars в Capacitor 8.6, без двойного сложения одного inset. Нижний отступ добавляет ещё 1rem.

Генератор custom-mode добавляет лишний inset адаптивным слоям, уже имеющим безопасные поля. Дополняющий скрипт записывает XML с прямыми ссылками foreground/background и monochrome, чтобы не уменьшать мотив дважды. Никаких ручных PNG-поправок в плотностях нет. Пакет SplashScreen 8.0.2: launchAutoHide=false, fade=0; скрытие после ready, включая ошибку чтения сохранения. Все проверки нативного вида — MT-022, не считаются выполненными браузером.
