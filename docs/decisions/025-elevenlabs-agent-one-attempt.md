# ADR-025: Агент генерирует музыку, эффекты и речь через ElevenLabs API — одна попытка на файл

**Дата:** 2026-11-12 · **Статус:** принято

## Контекст

Музыку пилота владелец генерировал вручную в интерфейсе ElevenLabs и загружал в репозиторий. Для потока новых дел это лишняя ручная работа. Генерация платная (кредиты), а лишние варианты и повторы быстро съедают бюджет.

## Решение

- Агент генерирует музыку (ElevenLabs Music), звуковые эффекты (Sound Effects) и речь (Text to Speech) через ElevenLabs API.
- **Ровно одна попытка на каждый файл.** Неудачный результат не перегенерируется без решения владельца.
- Ключ `ELEVENLABS_API_KEY` — только в GitHub Repository Secret или игнорируемом `.env.local`. Генерация — отдельный ручной запуск, не из обычного CI и тестов.
- Перед запуском — список файлов с длительностью и промптом; после — кредиты в devlog.
- Минимальная длительность задаётся параметром API (в интерфейсе сервис игнорировал длину из текста промпта).
- Голос рассказчика один на всю игру. Пилот озвучен Cartesia Sergei; новый голос ElevenLabs — только после одобрения владельцем по одной пробной фразе.

## Последствия

- Нужен скрипт генерации (по образцу `tools/generate-narration.py`) и ручной workflow с секретом. Это делается при первом использовании.
- Владелец добавляет `ELEVENLABS_API_KEY` в GitHub → Settings → Secrets and variables → Actions.
- Правила — `AGENTS.md` §7, `docs/CASE-RUNBOOK.md` (шаг 3, аудио), `docs/AUDIO-PLAN.md`.
