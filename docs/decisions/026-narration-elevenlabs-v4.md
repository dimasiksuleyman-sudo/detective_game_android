# ADR-026: Озвучка на ElevenLabs Eleven v4, два голоса

**Дата:** 2026-11-12 · **Статус:** принято (голоса — после прослушивания проб владельцем)

## Контекст

Пилот озвучен голосом Cartesia Sergei (ADR-017/018): 8 дорожек, ровная подача без эмоций. В сентябре 2026 вышла модель ElevenLabs **Eleven v4** (`eleven_v4`): 90+ языков, включая русский, лучше прошлых моделей следует «аудиотегам» — ремаркам в квадратных скобках (`[pauses]`, `[sighs]`, `[whispers]`, `[low, gravelly voice]`). Владелец решил переозвучить пилот в ElevenLabs.

## Решение

- **Модель:** `eleven_v4`, `language_code: ru`, MP3 44,1 кГц / 128 kbps. В игре — моно 64 kbps, −16 LUFS, как прежде.
- **Два голоса:** рассказчик (брифинг, реконструкция, объяснение) и Шеф (3 подсказки) — у Шефа есть портрет в труппе (`a16-chief`), отдельный голос делает его персонажем.
- **Текст игрока не меняется.** В `content/narration/elevenlabs.json` для каждой дорожки хранится «произносимая» версия:
  - числа и время словами: «23:30» → «половина двенадцатого ночи»;
  - теги подачи, например `[pauses]`;
  - ремарка роли в начале.

  Приложение по-прежнему сверяет запись с текстом дела: если текст в `case.json` изменился, скрипт отказывается генерировать, пока не обновлена произносимая версия.

- **Выбор голоса:** режим `voices` бесплатно сохраняет список русских мужских голосов библиотеки и их превью. Затем режим `sample` — одна пробная фраза на каждый из 1–3 кандидатов. Владелец слушает и выбирает. После этого `all` — все 8 дорожек.
- **Одна попытка на файл** (ADR-025). Файлы оригиналов не перезаписываются. Перегенерация — только по решению владельца: удалить файл и запустить снова.
- **Запуск:** вручную, `.github/workflows/narration-elevenlabs.yml` с секретом `ELEVENLABS_API_KEY`. Результат коммитится в ветку `audio/elevenlabs-narration`, откуда идёт PR в `main`.
- **Порядок:** полный набор генерировать **после** слияния работы агента над сейфом — она может поменять подсказки Шефа и объяснение финала.

## Последствия

- Cartesia остаётся в истории (`tools/generate-narration.py`). Workflow `cartesia-sample.yml` устарел: он привязан к удалённой ветке.
- Объём пилота ≈ 2000 знаков (с ремарками), плюс пробы ≈ 3 × 90 знаков.
- Новые дела озвучиваются теми же двумя голосами (`CASE-RUNBOOK.md`).
