# ADR-031: Сезоны — смена мира, стиля картинок и труппы

**Дата:** 2026-11-13 · **Статус:** принято владельцем (документы); код — отдельным PR перед сезоном 2.

## Контекст

Один и тот же нуарный город и одни и те же актёры со временем надоедают. Владелец хочет периодически «переворачивать доску»: другие страны, эпохи, времена года и даже реальность (пример — хай-тек дело в Антарктике, 2050), другие персонажи, стиль и цвета картинок. Интерфейс при этом остаётся единым. Новые дела доставляются обновлением в маркете или паками (M5) — для игрока оба варианта выглядят как «доступно обновление».

## Рассмотренные варианты

1. Оставить один мир и стиль навсегда — проще, но надоедает (отклонено владельцем).
2. Менять только место действия в рамках общего стиля и общей труппы — не даёт сменить эпоху и реальность.
3. **Сезоны:** блок из 4 дел со своим миром, стилем картинок, палитрой картинок и полностью новой труппой; интерфейс общий — **выбрано**.

## Решение

- **Сезон** = 4 дела. Внутри сезона мир, стиль картинок и труппа постоянны; между сезонами меняются полностью.
- **Труппа каждого сезона полностью новая** (решение владельца: так проще строить новые сюжетные линии). Актёры не переходят между сезонами. actorId уникальны во всей игре: префикс сезона, например `s02-a01-…`. Сезон 1 сохраняет текущие id `a01…a16` без переименования.
- **Шеф меняется каждый сезон** (решение владельца, по образцу сериалов-антологий вроде «Настоящего детектива»): новый персонаж — может быть женщиной, другого возраста, другой службы, — со своим голосом. Шеф входит в труппу сезона (`sNN-chief`, все 6 эмоций). Голос Шефа выбирается по одной пробной фразе и одобряется владельцем (AGENTS.md §7). Шеф сезона 1 — `a16-chief`, голос Nester Surovy.
- **Рассказчик** (Alex Bell) по умолчанию общий для всей игры — это «голос игры». Смена — только по решению владельца при старте сезона, по одной пробной фразе.
- **Интерфейс общий:** тёмная тема, шрифты, кнопки, иконка, сплэш не зависят от сезона. Палитра в `05-art-bible.md` §1 для UI остаётся общей; палитра картинок — своя у сезона.
- **Документы:** общие правила картинок — `05-art-bible.md` (форматы, размеры, процесс, портреты по мастеру, приёмка). Мир, строка стиля для промптов (STYLE_CORE сезона), палитра картинок, труппа и тон — в листе сезона `docs/seasons/season-NN-<slug>.md`. Сезон 1 — `docs/seasons/season-01-vetrogorsk.md`.
- **Рейтинг 12+ и правила честной дедукции** общие для всех сезонов. Жанр — детектив; реальность может быть фантастической, но разгадка выводится из улик, без «магии из ниоткуда».

## План кода (отдельный PR перед сезоном 2, не сейчас)

- `public/seasons/<seasonId>/season.json`: id, название, мир (короткий текст для ИИ), порядок дел, музыка сезона (необязательно).
- В деле `seasonId`; у старых дел по умолчанию `season-01`. Изменение схемы — через ADR, валидатор и миграцию пилота (правило AGENTS.md §3).
- S03 группирует дела по сезонам. Сохранения не меняются (caseId уже есть).
- Труппа сезона — `public/troupe/<seasonId>/…` или префикс id; сезон 1 остаётся на месте.
- Музыка: сезон может задать свои треки, иначе играет общая.
- Шеф: actorId и голос Шефа задаются сезоном (портрет в подсказках — если появится; озвучка подсказок — голосом Шефа сезона). Сейчас в коде Шеф не привязан к конкретному актёру, только роль `chief` в озвучке.
- ИИ-допрос получает текст мира сезона вместе с брифингом, чтобы персонаж 2050 года не говорил как житель нуарного портового города. Сейчас мир попадает в ИИ только через брифинг дела.

## Последствия

- Каждый новый сезон дороже обычного дела: пробная картинка стиля → одобрение владельца → мастер-портреты новой труппы (~6–10 актёров × 6 портретов) → дела.
- Размер: дело ≈ 6 МБ, сезон ≈ 30–40 МБ. Два-три сезона внутри APK допустимы; дальше старые сезоны — скачиваемые паки (M5).
- Строка меню «Ветрогорск · Дождь не смывает правду» привязана к сезону 1 — вопрос к владельцу перед сезоном 2 (см. STATUS).
