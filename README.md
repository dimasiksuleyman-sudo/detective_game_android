# Комната допросов (рабочее название)

Детективная игра для Android на **несколько игроков на одном телефоне** (hot-seat): игроки по очереди передают телефон, ведут собственное расследование, допрашивают подозреваемых и первыми пытаются назвать убийцу, мотив и способ.

- Допросы ведут ИИ-персонажи (через [aitunnel.ru](https://aitunnel.ru/), ключ пользователя), а без ключа и без сети игра проходится через заранее написанные вопросы.
- Новые дела выходят паками (JSON + картинки) и скачиваются без обновления приложения.
- Стек: Capacitor + React + TypeScript + Vite.

## Текущее состояние

Версия 0.3.2 / code 6; текущая ветка — `fix/interrogation-documents-audio`, один PR в `main`, APK собирает владелец локально.

- **M0** принят владельцем.
- **Классика (M1) и ИИ-допрос со своим ключом (M2)** работают. Ждут проверки на телефоне.
- **M3 в работе:**
  - готовы обложка, три локации, осмотр детали статуэтки и офлайн-озвучка Sergei;
  - все 58 игровых иллюстраций готовы: 52 заглушки заменены; S17 и оформление экранов реализованы; полная реплика, исходные документы и плеер ожидают приёмки MT-018.

Музыка, звуки и дождь работают офлайн, настройки независимы от озвучки. Готовы две музыкальные роли (меню и расследование), остальные используют fallback.

Подробности: [STATUS](docs/STATUS.md), [HOWTO](docs/HOWTO-run.md), [ручная очередь](docs/MANUAL-TEST-QUEUE.md).

**Работа с ветками:** каждый шаг — новая ветка от `main` и PR в `main`.

Быстрый запуск: Node 24 LTS (минимум 22.12) → `npm ci` → `npm run dev`. API-ключ не нужен.
